## 聴きどころ

- **0:16.5 と 0:19.2 は同じ高さ**（どちらも 249.9 Hz）。床では `！` が何も
  しません（60 本の平均でも −1.2 Hz・2/5）。**演技の層が、記号を演技に変えて
  いた**（0.7 では +42.2 Hz・5/5）。
- **0:26.7 の `？` だけ、床でも上がる**（+14.9 Hz・1 本）。60 本の平均では
  +13.1 Hz・5/5。**`？` はモデル自身が読む記号**で、演技の層を切っても残ります。
  音素列は末尾が `ne.` / `ne!` / `ne?` と違うだけ——同じ層でも記号によって
  扱われ方が違う。
- 見本は 1 本ずつ・seed 1 なので、実験の平均とは値が違う（向きは同じ）。
