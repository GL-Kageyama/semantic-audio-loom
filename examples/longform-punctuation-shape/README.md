## 聴きどころ

- **同じ seed で並べると、句点の側が毎回低い**（seed 1：359.6 → 333.6 Hz・
  302.4 → 288.7 Hz。seed 3：343.4 → 305.9・304.1 → 284.6）。
  **`！` は同じ。違うのは途中の 1 文字だけ。**
- **短い行の句点の落差が大きい**（seed 1 で −26.0・seed 3 で −37.5 Hz）。
  ただし上の表の差は**別々の行を同じ seed で鳴らした生の差**で、下の実験の
  「効き」（同じ行の中で `！` と `。` を比べた差）とは別の量。
  実験の効きは、9 文字の `、`→`。` で +39.3 → +15.2 Hz（−24.1 Hz）。
- 長い行は落差が小さい（−13.7 / −19.5 Hz）。**長い行は、もともと効きが弱い。**

⚠️ 見本は `script.yaml` から組むので強度 0.5。実験（`acting-punctuation-period/`・
`acting-punctuation-long/`）は llm 解決の none の Spec（強度 0.4）で、値は少し違う。
**向きは同じ**（実験：`！` の効き 9 文字 +39.3 → 途中に句点で +15.2 Hz・
24 文字 +22.0 → +13.2 Hz・すべて 5/5）。
