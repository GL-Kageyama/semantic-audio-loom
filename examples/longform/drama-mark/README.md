## 聴きどころ

- **0:30.4 → 0:33.4 は +88.6 Hz**。欄は 1 つも変えていない（sadness / strong / slow の
  まま）。文末の `。` を `！` にしただけで、声が開く。
- **0:17.0 → 0:21.8 は +3.4 Hz** しか動かない。この行は**途中に句点を 2 つ持つ長い行**
  で、記号の効きが行の形に飲まれる（18 本の平均でも +15.5 Hz で、3 行でいちばん小さい）。
- ⚠️ s31 の **+3.4 は 3 seed のうち最小**（平均 +15.5・+3.4〜+28.7）。見本は seed 2 で
  揃えたので、この行だけ低い側の 1 本になっている。**向き（正）は 9/9 で変わらない。**
- 見本は 1 本ずつなので、実験の平均とは値が違う。

音量：−17.89 LUFS・トゥルーピーク −1.06 dBTP → **目安（−16 ±1.0）に未達**（`--gain -0.35` でピークは門の内側）。
