# 聞き比べ — 同じ場面を、記号の書き方だけ変える

`projects/longform/experiments/demos/scripting-demo/` の 34.8 秒。同じ言葉の短い場面を 2 通りで並べる。
A は「。」で終わる書き方（いまの 2 作品の書き方）、B は途中の句点を外して、強く
出したい行を「！」にした書き方。**台詞の言葉は同じで、句読点だけが違う。**
2 本目と 3 本目（`でも、風邪ひいてない？`）は両方に同じ台詞・同じ seed で置いた対照。

## 聴きどころ

- **A と B の差は、書き方だけ。** 同じ声・同じ seed・同じ欄（neutral / moderate /
  controlled）で、真白の 1 行目が **+53.7 Hz**、ニジが **+32.1 Hz** 高くなる。
  1 行ずつ測った実験の値（9 文字の `！` で +39.3 Hz・`experiments/punctuation/acting-punctuation/`）と
  同じ向きで、**場面の単位でも効く**。
- **0:12.1 と 0:27.0 は同じ音**（どちらも 319.4 Hz・2.62 秒）。書き方を変えたところと
  変えていないところが、耳でも分かれる。
- 真白の 1 行目だけ **3.97 → 3.60 秒**と短くなる。「。」で文を切ると、そこで一度
  落ちてから次の文へ移る読み方になる——**記号は間ではなく高さ**、という
  `experiments/punctuation/acting-punctuation/` の読み方と同じ向き（無音率も 0.224 → 0.129）。
