## 聴きどころ

- **最初の 2 本は同じ音。** 同じ台詞・同じ seed で、f0 も長さも同じ（320.4 Hz・2.50 s）。
  ⚠️ **md5 は一致しなかった**（差は RMS −67.7 dBFS・最大 0.006＝聞こえない）。
  実験の seed 1〜3 でも同じ大きさの差が出る（−68〜−75 dBFS）。
- **途中の `…` の行だけ短い**（1.95 s）。差の 0.55 秒は、間ではなく**読み方の速さ**。
  実験（強度 0.4）では 2.918 → 2.073 秒で、無音率も 0.315 → 0.195 に下がった。
- 見本は強度 0.5（`script.yaml` の既定）。実験は llm 解決の none の Spec（強度 0.4）
  なので、**差の大きさは少し違う**。向きは同じ。
