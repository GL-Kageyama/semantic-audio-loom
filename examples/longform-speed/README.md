## 聴きどころ

- **0:05.1 と 0:12.4 は長さが 1.9 秒違うのに、高さは 8.1 Hz しか違わない**
  （275.7 と 283.8）。速さは長さのノブ（36 本の実験でも 3.9 → 2.1 秒・f0 は
  −5.4〜+8.2 Hz）。
- **0:20.7 と 0:23.8 は長さがほぼ同じ（2.97 と 2.85 秒）で、高さが +32.5 Hz**。
  記号が変えるのは高さと抑揚（6.0 → 8.4 半音）。
- **0:26.9 は速い行でも `！` が効く**（+40.3 Hz）。**0:38.2 は声を替えても効く**
  （+41.0・36 本の実験で 18/18）。
- 見本は 1 本ずつ・seed 2 なので、実験の平均とは値が違う（向きは同じ）。seed 1 は
  偶然 very_slow が −13.0 Hz と大きく下がったので、3 seed の真ん中の seed 2 を使った。

音量：−16.96 LUFS・トゥルーピーク −1.20 dBTP・LRA 2.60（配布の目安の内側）。
`deliver.py` の既定のゲインは −0.56 dB（ピークの門で止まる）。**−0.60 で試すと −17.06
LUFS で目安の外へ出た**ので、`--gain -0.50` で書いた。
