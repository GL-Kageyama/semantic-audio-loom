## 聴きどころ

- **0:08.7 と 0:25.1 は同じ高さ**（どちらも 313.0 Hz）。**中性に `！` を付けた声と、
  悲しみに `！` を付けた声は、高さが同じ**——36 本の実験でも 338.0 と 337.7 Hz。
  **低い感情の上にも、記号は同じだけ足せる**（+29.2〜+36.4 Hz・この 5 組で 5/5）。
- **0:21.8 → 0:25.1 は、感情を変えずに記号だけで +29.2 Hz**。感情そのものの効き
  （sadness は `。` で 283.8、neutral の 280.5 から +3.3）よりずっと大きい。
- 感情ごとに `。` の高さが違う（280.5〜305.9）のに、`！` を足すと 313.0〜339.4 と
  揃って上がる。**記号の効きは感情の上に乗る**（幅は 1 本ずつで ±20 Hz ほど動く）。

音量：−16.97 LUFS・トゥルーピーク −1.26 dBTP・LRA 2.60（配布の目安の内側）。
`--gain -0.56`（既定の式がピークの門で出した値）で書いた。
