# 同じ Spec・同じ seed でも、プロセスを分けると音が 2 つに割れる

`seed` は「同じ seed なら byte-identical」と書いてあるが、それは**同じプロセスの中**の話
だった。同じ 1 本（joy・moderate・speed natural・delivery controlled・breathiness none・
beta 0.7・seed 3）を、**別プロセスで 6 回**作って md5 を比べた。

| run | md5（先頭 7 桁） |
| --- | --- |
| 1 | `954f9db` |
| 2 | `954f9db` |
| 3 | `954f9db` |
| 4 | `2d575e2` |
| 5 | `2d575e2` |
| 6 | `2d575e2` |

**6 本が 2 種に割れた（3＋3）。**

## 差は −64 dBFS・数字は動かない

| 測ったもの | 2 種のあいだ |
| --- | --- |
| 長さ | 同じ（65,950 サンプル・2.748 秒） |
| ピーク | 同じ（0.94995） |
| 最大差 | 0.0119 |
| RMS 差 | **−64 dBFS**（波形の RMS の 0.36%） |
| 相関 | 0.999994 |
| `act_probe.py` の 14 欄 | **全部同じ**（f0 314.9 Hz・抑揚 8.4 半音・間 0.184 …） |

差は**発話の真ん中**に寄り、頭と尻尾（無音）では 0。**最も大きい 10% の区間で RMS 差
0.00125。**

## プロセスの中では一致する

- 同じプロセスで 3 回続けて作ると、差は **3e-6（1 LSB）**。
- メモリのアラインメントをずらして（1,000〜3,000 要素の配列を挟んで）作り直しても、
  差は 3e-6 のまま。
- **1 スレッドに絞っても（`OMP_NUM_THREADS=1`）、2 種に割れる。**

→ **プロセスをまたぐ何か**が最後の桁を変えている。**1 スレッドでもアラインメントでもない。**
（CPU のコア種か BLAS のカーネル選択あたりが疑わしいが、**特定していない**。）

## どこで見えたか

- `acting-pitch-ladder/` と `acting-emotion-ladder/` は、**name 以外まったく同じ** Spec を
  持つ cue を 1 本ずつ含む（`pl-natural-s3` と `el-joy-s3`）。seed 1・2・4・5 は
  **md5 が一致**し、**seed 3 だけ一致しなかった**。
- つまり**起きるのは稀ではなく、条件しだい**（この 6 回では 3 回目と 4 回目のあいだで
  切り替わった）。

## 何が困るか、何が困らないか

- **困らない**：演技の測定（f0・長さ・抑揚・間・張り）は 14 欄すべて同じ数字を出す。
  **測った結論はこの差に影響されない。**
- **困る**：`md5` で「同じ音か」を検査すること。**同じ Spec を焼き直しても md5 は
  一致しないことがある。** 一致を見るなら同じプロセスで 2 回作る。
- 音としては −64 dBFS。**聞いて区別できない。**

## 測る

```bash
bash projects/longform/determinism/run.sh 6      # 6 回（1 回ごとにモデルのロードがある）
```

`takes/` に 1 回ごとの WAV が残る（`run-1.wav` …）。
