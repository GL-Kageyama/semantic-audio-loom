# 同じ Spec・同じ seed でも、焼き直すと音が 2 つに割れる

`seed` は「同じ seed なら byte-identical」と書いてあるが、**そうならない。**
同じ 1 本（joy・moderate・speed natural・delivery controlled・breathiness none・
beta 0.7・seed 3）を、**別プロセスで 6 回**作って md5 を比べた。

| run | md5（先頭 7 桁） |
| --- | --- |
| 1 | `954f9db` |
| 2 | `954f9db` |
| 3 | `954f9db` |
| 4 | `2d575e2` |
| 5 | `2d575e2` |
| 6 | `2d575e2` |

**6 本が 2 種に割れた（3＋3）。**

## 差は −64 dBFS・数字は動かない

| 測ったもの | 2 種のあいだ |
| --- | --- |
| 長さ | 同じ（65,950 サンプル・2.748 秒） |
| ピーク | 同じ（0.94995） |
| 最大差 | 0.0119 |
| RMS 差 | **−64 dBFS**（波形の RMS の 0.36%） |
| 相関 | 0.999994 |
| `act_probe.py` の 14 欄 | **全部同じ**（f0 314.9 Hz・抑揚 8.4 半音・間 0.184 …） |

差は**発話の真ん中**に寄り、頭と尻尾（無音）では 0。**最も大きい 10% の区間で RMS 差
0.00125。**

## プロセスの中でも、いつもは一致しない

- 同じプロセスで 12 回続けて作ると（`within_process.py 12`）、**1 回目だけが違い、
  2〜12 回目は同じ**。差は **3e-6（1 LSB）**、2 回目以降どうしは 0。
- **1 つのプロセスで 25 本まとめて焼くと、いつも同じとは限らない。**
  `experiments/subtext/acting-subtext/` の 25 本では **seed 3 だけが 2 種に割れた（3＋2）**——
  1 つの `build_voice.py` の中、同じ Spec、同じ seed、`f0_end_st_s` だけが
  −3.60 と −3.85 半音に分かれた。ほかの 4 seed は 5 通りとも一致。
- **同じ台本をもう 2 回焼くと、1 回は 25/25 が元と一致し、1 回はその 2 本だけが
  逆の型になった**（その回の none と同じファイル・byte-identical。差は最大 0.0093・
  RMS −54.2 dBFS）。割れる位置は 3 回とも同じ 2 本（台本の 8 本目・18 本目）。
  ＝ばらつくのは「その回にどちらの型へ落ちるか」で、cue の中身では決まらない。
- メモリのアラインメントをずらして（1,000〜3,000 要素の配列を挟んで）作り直しても、
  差は 3e-6 のまま。**1 スレッドに絞っても（`OMP_NUM_THREADS=1`）、2 種に割れる。**

→ **最後の桁を変えている何かは、プロセスの外だけではない。** 1 スレッドでも
アラインメントでもない（CPU のコア種か BLAS のカーネル選択あたりが疑わしいが、
**特定していない**。seed 3 が毎回そろうのは、その seed の軌道が丸めの境目の
近くを通るため、というのが今の見立てで、**証拠は無い**）。

## どこで見えたか

- `experiments/pitch/acting-pitch-ladder/` と `experiments/basics/acting-emotion-ladder/` は、**name 以外まったく同じ** Spec を
  持つ cue を 1 本ずつ含む（`pl-natural-s3` と `el-joy-s3`）。seed 1・2・4・5 は
  **md5 が一致**し、**seed 3 だけ一致しなかった**。
- つまり**起きるのは稀ではなく、条件しだい**（この 6 回では 3 回目と 4 回目のあいだで
  切り替わった）。

## 何が困るか、何が困らないか

- **困らない**：演技の測定（f0・長さ・抑揚・間・張り）は、プロセスをまたいだ 2 種でも
  14 欄すべて同じ数字を出した。**測った結論はこの差に影響されない。**
- **困る**：`md5` で「同じ音か」を検査すること。**同じ Spec を焼き直すと md5 は
  一致しないことがあり、それは同じプロセスの中でも起きる。** 一致の検査に md5 を
  使わない（測る欄で比べる）。
- 音としては −64 dBFS。**聞いて区別できない。**
- ⚠️ ただし、1 つのプロセス内で割れたときは **測る欄も 1 つ動いた**
  （`experiments/subtext/acting-subtext/` の seed 3・`f0_end_st_s` が 0.25 半音）。**「14 欄が同じ」は
  プロセスをまたいだ 2 種で測った話**で、どの割れ方でも同じとは限らない。

## 測る

```bash
bash projects/longform/experiments/analysis/determinism/run.sh 6      # 6 回（1 回ごとにモデルのロードがある）
```

`takes/` に 1 回ごとの WAV が残る（`run-1.wav` …）。

```bash
PY=/Users/user/sonic-loom-spike/venv_tsukasa/bin/python
PYTHONPATH=. $PY projects/longform/experiments/analysis/determinism/within_process.py 12   # 1 プロセスで 12 回
```

`within_process.txt` に 1 回ごとの md5 と 1 回目からの最大差が出る
（seed 3 の `pl-natural-s3`。`1 8013f1b 0.000000` / `2 8b3e2de 0.000003` …）。
