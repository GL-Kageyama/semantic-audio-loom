# explainer-level — 解説の 48 キューを測る

「音は、なぜ感情を動かすのか」の 48 本（語り手 44・実例の真白 4）を、キューごとに測った。
真白の 4 本は同じ台詞「明日、また来るね。」を 4 通りに演じたもの
（neutral/moderate/controlled・joy/strong/cheerful・sadness/strong/restrained・joy/subtle/gentle）。

## 何が分かったか

| 項目 | 語り手（44 本） | 真白（4 本） |
| --- | --- | --- |
| f0 の中央値 | 261.4 Hz（237.9–295.5） | 351.4 Hz（326.0–355.5） |
| 抑揚（平均） | 9.92 半音 | 8.80 半音 |
| 間（平均） | 0.215 | 0.240 |

包絡（LPC 26 次・64 点・dB・RMS 距離）:

| 比べるもの | 距離 |
| --- | --- |
| 語り手 44 本の中心 ↔ 真白 4 本の中心 | **4.68 dB** |
| 語り手の中の広がり（946 組の中央値） | 1.40 dB |
| 真白 4 本の広がり（6 組の中央値） | **0.50 dB**（0.11–0.64） |
| 参照どうし（`female_mature_p294` ↔ `mashiro`） | 4.68 dB |
| 語り手の中心 ↔ 自分の参照 | 2.13 dB |
| 真白の中心 ↔ 自分の参照 | 2.68 dB |

- **語り手と真白は、声質でも高さでも分かれる。** 中心どうしは 4.68 dB で、語り手の中の
  広がり（1.40）の 3 倍以上。高さは 90 Hz 離れていて、44 本の最大（295.5）と 4 本の
  最小（326.0）が重ならない。
- **演技は、声質をほとんど動かさない。** 同じ台詞を 4 通りに演じても、包絡は 0.50 dB しか
  動かない（参照を替えると 4.68 dB）。一方で高さは 326.0–355.5 Hz と 29.5 Hz 動く。
  **演技で動くのは状態で、器ではない**——作品の段でも同じ。
- **分かれるかどうかは、参照の組で決まる。** 真白↔ニジの参照は 1.22 dB で、参照
  ライブラリの中でいちばん近い。だから演劇の二人は声質で分かれない（帯域で分けた）。
  語り手↔真白は 4.68 dB なので、分かれる。
- **同じ人物でも、作品が違えば高さは動く。** この解説の真白は 351.4 Hz、演劇の真白は
  304.1 Hz（0.7 版・47 本の中央値）。**同じ参照・同じ人物で 47 Hz。** 台詞の感情の
  混ざり方が違うため。ただし比べている本数が 4 と 47 で違う（4 本は同じ 1 行）。

## 限界

- 真白は 4 本だけで、しかも全部同じ 1 行。**人物の代表値としては薄い。**

- 人が聴いて確かめた分離ではない。
