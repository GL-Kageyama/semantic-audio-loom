# 文中の `？` も効く（`！` の 1/3。位置も足し算の形も同じ）

`experiments/punctuation/acting-punctuation-mid-exclaim/` と同じ行（y06・ニジ・joy・18 文字）で、記号だけを
`？` に替えた（4 通り × seed 5 = **20 本**）。欄は台本のまま。台本は
[`make_script.py`](make_script.py) が作る。

| 通り | 台詞 | f0（5 本の平均） | 台本のままとの差 |
| --- | --- | --- | --- |
| `base` | 黒くて、太ってて、こっちを見てた。 | 312.7 Hz | — |
| `end` | 黒くて、太ってて、こっちを見てた**？** | 324.8 | **+12.1**（5/5） |
| `mid` | 黒くて、太ってて**？**こっちを見てた。 | 324.6 | **+11.9**（5/5） |
| `both` | 黒くて、太ってて**？**こっちを見てた**？** | 337.6 | **+24.9**（5/5） |

- **`？` は `！` より小さい**：文末 +12.1（`！` は +36.8）・途中 +11.9（`！` は +23.1）・
  両方 +24.9（`！` は +61.1）。**文末では 1/3**。
- **位置の効き方は同じ**：途中でも上がり、両方で足し算になる（11.9 + 12.1 = 24.0 対
  実測 24.9）。
- `！` と違って**途中の `？` は行を 0.27 秒伸ばす**（4.26 → 4.53）。文末の `？` は 0.10 秒
  縮む（4.16）。**質問の記号は、途中では間になる。**
