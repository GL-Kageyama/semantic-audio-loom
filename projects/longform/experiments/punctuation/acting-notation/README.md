# 表記は音を変えない。読点は、高さを下げる

`明日、また来るね。` の「また」だけを書き換えた（4 通り × seed 5 = 20 本・beta 0.7）。
Spec は 4 通りで共通。

    PYTHONPATH=. $PY projects/longform/experiments/punctuation/acting-notation/run.py
    PYTHONPATH=. $PY bin/act_probe.py --tsv …/voice/*.wav > probe.tsv

| 台詞 | f0 中央値（seed 5 の平均） |
| --- | --- |
| 明日、**また**来るね。 | 297.2 Hz |
| 明日、**マタ**来るね。 | 297.2 Hz |
| 明日、**又**来るね。 | 297.2 Hz |
| 明日、**また、**来るね。 | 280.2 Hz |

## 2 つのこと

1. **かな・カナ・漢字は、音が 1 ビットも変わらない。** seed 1〜3 で md5 が 3 組とも
   一致した（`hira` = `kata` = `kanji`）。**モデルは表記を音へ正規化している。**
   字面で効くのは「記号を足す・替える」だけで、書き方ではない。
2. **読点を 1 個足すと、声が下がる**（297.2 → 280.2 Hz・**−17.0 Hz**）。
   5 本のうち 4 本が下がり、長さは +0.03 秒（3/5）で**間にはならない**。
   **読点は、間ではなく高さの印**——文末の `？`/`！` が上げるのと逆の向きで、
   同じ「高さのノブ」の一部。

## 効き目の並び（同じ 1 行・beta 0.7）

| 字面の変更 | f0 |
| --- | --- |
| かな → カナ → 漢字 | 0 Hz（md5 まで同じ） |
| 読点を 1 個足す | **−17.0 Hz**（4/5） |
| 文末を `？` に | **+16.3 Hz**（5/5） |
| 文末を `！` に | **+39.3 Hz**（5/5） |

⚠️ 読点の実験は n=5・符号 4/5 で、効果の向きは揃っているが幅は測っていない
（1 本ずつの値は `probe.tsv`）。
