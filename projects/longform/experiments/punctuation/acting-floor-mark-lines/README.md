# 床で消える `！` の効きは、行と声を替えても消える

`experiments/punctuation/acting-punctuation-floor/` は 1 行（`明日、また来るね`）・1 声（真白）で、`！` は床
（`beta` 0.0）で −1.2 Hz・`？` は +13.1 Hz だった。**行と声を替えても同じ向きか**を
確かめる。行 3 つ（途中に読点のある 2 行＋読点の無い 1 行）× 声 2（真白・ニジ）×
`beta` 2 段（0.0 / 0.7）× 末尾 2（`。` / `！`）× seed 3 = **72 本**。
ほかの欄は共通（neutral・moderate・speed natural・pitch natural・delivery controlled・
breathiness none）。

    PYTHONPATH=. $PY projects/longform/explainer/build_voice.py --dir projects/longform/experiments/punctuation/acting-floor-mark-lines
    PYTHONPATH=. $PY bin/act_probe.py --tsv …/voice/*.wav > probe.tsv

## 読み方

- **向きは 6/6 で同じ。** 0.7 ではどの行・どの声でも `！` が上がる（+39.0〜+95.4・
  すべて 3/3）。**床では 6 組とも +7.2 Hz 以下**で、正だった 4 組は 0.7 の
  **3.6〜10.9%**、残る 2 組は負。
  `！` の効きが演技の層から来ている、という読みはこの 6 組で裏づけられる。
- **床の値は 0 ちょうどではない。** `今、行くよ` は +6.0 / +7.2 Hz（どちらも 3/3）で、
  弱いが向きは揃う。**床でも少しは効く**（記号が音素列に残るため）。
  0 に見えるのは読点の無い `そこにいて`（−1.2 / −1.6・0/3）。
- **0.7 の大きさは、行で 2 倍以上ちがう**（+39 と +95）。いちばん大きいのは
  読点の無い `そこにいて`——**途中に切れ目がある行は効きが小さい**という
  `experiments/punctuation/acting-punctuation-long/` の傾向と同じ向き。ただしここは 1 行ずつ・seed 3 本なので、
  **大きさの順位づけには使わない**。
- ここでは `？` を振っていない（`experiments/punctuation/acting-punctuation-floor/` の 1 行だけ）。

⚠️ 1 行あたり seed 3 本（5 本ではない）。neutral だけ。行の長さも揃っていない
（`そこにいて` は読点が無い）。
