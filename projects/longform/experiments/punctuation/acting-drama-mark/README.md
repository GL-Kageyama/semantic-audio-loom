# 作品の台詞に `！` を書いたら、声は動くか

`drama/script.yaml` の **`intensity: strong` の 9 行すべて**を、**そのまま（文末 `。`）**と
**文末だけ `！`**にして焼いた（9 行 × 2 記号 × seed 3 = **54 本**）。感情・強度・声量・
速さ・`delivery` は台本のまま、seed は 1〜3、beta 0.7（作品と同じ）。

## 読み

- **作品の台詞でも、`！` は効く**（27/27 で正）。欄を 1 つも変えず、文末の 1 字だけで
  声が上がる。**強さを台詞に書けば、欄をいじらなくても出る。**
- **いちばん大きいのは、ひとことの行**（s65「ニジ！」で +120.2 Hz）。**いちばん小さいのは
  途中に句点を 2 つ持つ長い行**（s31 で +15.5）。**行が短いほど、記号が強く出る**
  （s31・s28 はいずれも途中に句点を持ち、効きが半分以下）。
- s30 は途中に句点を持つのに +52.9 で大きい（s31 と同じ 2 つの句点）。**句点の数だけでは
  説明できない**——行の長さ・語尾の形も効いている。**1 つの型では言えない**。
- ⚠️ seed 3 本では幅が広い（s63 は +2.5〜+88.6・s65 は +57.0〜+172.9）。**向きは 27/27
  で揃うが、1 本ずつの大きさは seed で 2 倍以上動く**（seed の揺れは 84.6〜92.7 Hz・
  `REPORT.md`）。行ごとの値は `probe.tsv`。
- 長さは `！` で 0.00〜0.28 秒縮む。
