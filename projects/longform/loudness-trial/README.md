# 圧縮は掛けない（通常盤で配布する）——掛け方と代償は残す

**裁定（2026-11-01）：配布は圧縮なしの通常盤。掛けた mp3 は比較用にここへ置く。**
耳では差が小さく、**掛ける前のほうが情報量が多い**（下の測定）。門（−16 ±1.0 LUFS）に
届かない 10 本は**未達のまま**残す——届かないことを直さず、届かないと記録する。

## 何をしたか

`deliver.py` は**直線のゲインだけ**を掛ける。ピークに当たった素材は −16 LUFS に届かない。
ここでは未達の 2 本の**マスターの wav** に `loudnorm` の 2 パス
（`I=-16:TP=-1.0:LRA=11`・`linear=false`＝動く圧縮）を掛けて、**届くか・何を失うか**を
測った。マスターは書き換えていない。

| 作品 | 段 | 音量 LUFS | ピーク dBTP | 幅 LRA | 波高率 dB |
| --- | --- | --- | --- | --- | --- |
| `explainer`（5:11） | 掛ける前 | −17.44 | −0.42 | 8.30 | 21.2 |
| | 掛けた後 | −16.28 | −1.24 | 7.20 | 19.2 |
| `drama-scene-mark`（1:44・声だけ） | 掛ける前 | −20.91 | −0.44 | 12.50 | 23.2 |
| | 掛けた後 | −16.38 | −1.23 | 7.40 | 17.9 |

- **2 本とも門に入る**（−16 ±1.0・TP ≤ −1.0・LRA ≤ 12）。
- 声だけのほうが掛かりが大きい（+4.5 dB・波高率 −5.3 dB）。解説は +1.2 dB（−2.0 dB）。

## 情報量はどちらが多いか（伝達の表）

100 ms ごとの momentary loudness を**同じ時刻で**突き合わせ、**掛ける前の高さ 8 帯**に
分けて、それぞれ何 dB 上がったか（[`measure_quiet.py`](measure_quiet.py)）。

| 帯（掛ける前・dB） | `explainer` の上げ | `drama-scene-mark` の上げ |
| --- | --- | --- |
| −49.9〜−44.8 | +1.9 | +5.7 |
| −44.8〜−39.8 | +1.9 | +4.8 |
| −39.8〜−34.7 | +2.0 | +6.1 |
| −34.7〜−29.6 | +2.3 | +6.2 |
| −29.6〜−24.6 | +1.9 | +6.8 |
| −24.6〜−19.5 | +1.7 | +5.5 |
| −19.5〜−14.5 | +1.2 | +4.7 |
| −14.5〜−9.4（`drama` は −16.4〜−11.6） | +1.1 | +2.5 |

- **小さい音ほど大きく上がる**（`drama` は谷 +4.8〜+6.8 に対し山 +2.5 dB）。
  **山と谷の差が縮む＝そこにあった情報が減る。** 幅（LRA）が 12.50 → 7.40 と半分近く
  落ちるのがその会計。解説はもともと起伏が小さく、掛かりも小さい（+1.1〜+2.3 dB）。
- 上げ幅の差が一番大きいのは**声の小さい行と長い間の周り**。息づかい・間際の子音は、
  圧縮すると同じだけ持ち上がる。

**つまり、音量の門に通すための 4.5 dB は、谷を持ち上げて買っている。**

## なぜ通常盤を採るか

1. **耳で差が小さい**（2026-11-01・著者の聴取）。2 本を聴き比べて、優劣が付かなかった。
2. **差が付かないなら、情報量の多いほうを残す。** 測ると、掛けた側は谷が +2〜+7 dB
   上がり、幅が 1.1・5.1 LU 縮んでいる。**戻せない減り方**（元の谷は復元できない）。
3. 門は**作品の質の門ではなく、配布の目安**。届かない 10 本は「未達」として記録し、
   音量を揃えるために音を削らない。

## 残すもの（掛け方）

掛け方は、**同じ原因（ピークに当たって −16 に届かない）が別の作品で出たとき**に
そのまま使える。数字は全部このフォルダに残す。

```bash
# 2 パス（1 パス目で測り、2 パス目で当てる）＝動く圧縮。mp3 をここに書き出す。
PYTHONPATH=. <venv>/bin/python projects/longform/loudness-trial/make_trial.py

# 掛けた後の情報量を、入力の高さごとに測る（伝達の表）。
PYTHONPATH=. <venv>/bin/python projects/longform/loudness-trial/measure_quiet.py
```

- 掛けた mp3 は **`examples/` に足さない**（配布物ではない）。比較用にここへ置く。
- 数は [`result.tsv`](result.tsv)（前後の I・TP・LRA・ピーク・RMS・波高率）。
- ⚠️ **質感（子音の立ち方・息の量）は測っていない。** 聴いて決める段で、
  今回の裁定は「差を感じない」だった。別の素材では聴き直しが要る。
