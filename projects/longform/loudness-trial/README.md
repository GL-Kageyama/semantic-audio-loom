# 圧縮を掛けたら、未達はどこまで届くか（測るだけ・裁定はまだ）

`deliver.py` は**直線のゲインだけ**を掛ける（ピークに当たった素材は −16 LUFS に
届かない）。ここでは未達の 2 本の**マスターの wav** に `loudnorm` の 2 パス
（`I=-16:TP=-1.0:LRA=11`・`linear=false`＝動く圧縮）を掛けて、**届くか・何を失うか**を
測った。掛けた mp3 はこのフォルダに置く（`examples/` には足さない——掛け方はまだ裁定
されていない。聴いて決めるため）。

| 作品 | 段 | 音量 LUFS | ピーク dBTP | 幅 LRA | 波高率 dB |
| --- | --- | --- | --- | --- | --- |
| `explainer`（5:11） | 掛ける前 | −17.44 | −0.42 | 8.30 | 21.2 |
| | **掛けた後** | **−16.28** | −1.24 | 7.20 | 19.2 |
| `drama-scene-mark`（1:44・声だけ） | 掛ける前 | −20.91 | −0.44 | **12.50** | 23.2 |
| | **掛けた後** | **−16.38** | −1.23 | **7.40** | 17.9 |

- **2 本とも門に入る**（−16 ±1.0・TP ≤ −1.0・LRA ≤ 12）。門は音量と幅の両方。
- **声だけのほうが、掛かりが大きい**。−20.91 → −16.38（**+4.5 dB**・波高率 −5.3 dB）、
  幅も 12.50 → 7.40。**間と静かな行が 4〜5 dB 持ち上がる**——LRA が下がるのは、
  山が下がったのではなく**谷が上がった**から。長い間（最長 6 秒）を含む素材では、
  呼吸の音も同じだけ上がる。
- 解説は +1.2 dB で済む（波高率 −2.0 dB）。**山と谷の差がもともと小さい**ため。
- ここで測ったのは音量だけ。**声の質感（子音の立ち方・息の量）は測っていない**——
  耳で聴いて決める段（`explainer-compressed.mp3`・`drama-scene-mark-compressed.mp3`）。
