# 山場の強さは、`！` がひとつしかないことから来ている

`drama/script.yaml` の終わりの場面（s60〜s72・13 行）で、**`intensity: strong` の 3 行
（s61・s63・s65）にだけ `！` を置いた版**（`strong`）と、**台本のまま**（`asis`）を
seed 1〜5 で焼いた（13 行 × 条件 2 × seed 5 = **130 本**）。欄・`pause_before` は台本のまま。
台本は [`make_script.py`](make_script.py) が作る。

## 行ごと（seed 5 本の平均）

| 行 | 台本のまま | 強い 3 行に `！` | 差 |
| --- | --- | --- | --- |
| s60 niji joy | 303.7 Hz | 303.7 | 0 |
| **s61 mashiro sadness（strong）** | 278.4 | 325.9 | **+47.5** |
| s62 niji joy | 298.7 | 298.7 | 0 |
| **s63 mashiro sadness（strong）** | 279.0 | 329.8 | **+50.8** |
| s64 niji calm | 259.6 | 259.6 | 0 |
| **s65 mashiro fear「ニジ。」（strong）** | 291.6 | 380.7 | **+89.1** |
| s66 niji joy | 314.7 | 314.7 | 0 |
| s67 mashiro fear「ニジ！」（もとから `！`） | 391.0 | 391.0 | **0** |
| s68〜s72 | — | 同じ | **0** |

- **動くのは、記号を置いた 3 行だけ**。ほかの 10 行は 1 seed ずつ見ても値が同じ
  （`！` を写した行だけが動く）。差は
  [`drama-scene-mark-seed/`](../drama-scene-mark-seed/) の全部 `！` 版と同値（+47.5・+50.8・
  +89.1）——同じ行・同じ seed なら同じ音。

## 山場（s67）は残るか —— **残らない**

| seed | s67（両条件で同じ） | 次点との差：台本のまま → 強い 3 行に `！` | s67 の順位 |
| --- | --- | --- | --- |
| 1 | 453.1 Hz | +123.4 → **+12.9** | 1 位 → 1 位 |
| 2 | 320.4 | +0.0 → **−45.5** | 1 位 → 3 位 |
| 3 | 453.1 | +127.1 → **+23.0** | 1 位 → 1 位 |
| 4 | 427.6 | +74.2 → **+14.5** | 1 位 → 1 位 |
| 5 | 300.6 | +15.2 → **+0.0** | 1 位 → 1 位 |

**3 行に置いただけで、s67 と次点の差の平均は 68.0 → 1.0 Hz。** 全部（12 行）に置くと
−43.3 Hz（[`drama-scene-mark-seed/`](../drama-scene-mark-seed/)）。**置く行が増えるほど、
山は低くなる**（0 行 68.0 → 3 行 1.0 → 12 行 −43.3）。

## 読み

- **山場がいちばん高いのは、その場面に `！` がひとつしかないから**。s67 の高さは
  両条件で同じ（同じ行・同じ seed）なのに、ほかの行が `！` を得た瞬間に追いつかれる。
- **`！` は「強くする」道具でなく「ほかと差をつける」道具**。全部に配ると差は消える。
  強くしたい行を選び、**それ以外は「。」のまま**にする。
- ⚠️ s67 自身の高さも seed で 300.6〜453.1 Hz と大きく動く。**順位で読む**（seed 5 本で
  1 位 → 3 位・1 位・1 位・1 位）。値ひとつで「山場が高い」と言わない。
