# 台本の書き方 — 声を動かすのは、どこか

測った結果から、台本を書く人向けにまとめた 1 枚。数はすべて f0 中央値の差
（seed 5 の対・beta 0.7 の既定）。詳しい測定は各実験の README と
[`REPORT.md`](REPORT.md) の「答え」。

## 頼れる順

| 書くこと | 声への効き | 頼れるか |
| --- | --- | --- |
| 間（`pause_before`） | 長さそのもの | **頼れる**（台本の欄で決まる） |
| 文末を `！` に | **+39〜+79 Hz**（声によって変わる・5/5）。24 文字の行では +13〜+22 Hz | **頼れる**（向きは同じ・幅は行の形で縮む） |
| 文末を `？` に | **+16.3 Hz**（5/5） | 頼れる |
| 速さ（`speed`） | 早口 5/5・間 5/5 | **頼れる**（beta に依らない） |
| 読点を 1 個足す | **−17.0 Hz**（4/5）・長さは動かない | 向きは揃うが幅は未測 |
| 感情・強度の欄 | neutral 比 +4〜+26 Hz（10 語）・強度 +20〜+45 Hz（beta 0.3 のみ） | **seed の揺れ（84.6 Hz）より小さい** |
| delivery | 幅 45 Hz（beta 0.3）・0.7 では揺れの中 | beta を下げるときだけ |
| 声量（`volume`） | 0（ミックスの利得で作る） | 使えない |
| 表記（かな・カナ・漢字） | 0（md5 まで同じ） | 使えない |
| 裏の意味（`subtext`） | 0（rule）・+6.9 Hz（llm の強度の段だけ） | 演出の記録としては残す |

## 実務の指針

1. **強く出したい行は、欄を振るより「！」を書く。** 短い行ほどよく動く
   （9 文字 +39・24 文字 +13〜+22 Hz）。24 文字の行でも、途中を句点で
   切らず読点でつなぐと効きが戻る（+13.2 → +22.0）。
   記号を重ねても増えない（`？！` は `！` と同じ）。
   いまの 2 作品は 137 行中 136 行が「。」で終わっていて、いちばん強いノブを使っていない。
2. **間は台詞の読点で作らない。** `pause_before` と `assemble.py` で作る。
   読点は高さを下げるだけ（−17 Hz）。
3. **表記は自由。** 読みの指定が要るとき以外は、かな・漢字の選択は音に出ない。
4. **欄を効かせたいなら beta 0.3。** 0.7 では感情・強度は seed の揺れに埋もれる。
   ただし字面の効き（記号）は beta 0.3 で縮む（+39.5 → +25.4 Hz）。
5. **seed は固定して読む。** seed を替えると f0 が 84.6〜92.7 Hz 動く。
   台本の比較は同一 seed で。
6. **subtext は書いてよい。** 音にはまだ乗らないが、記録として残り、
   llm 解決では強度の段に効く（+6.9 Hz）。
