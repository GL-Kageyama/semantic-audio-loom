# `！` の効きは演技の層が作っている。`？` は地の読みが作っている

文末の記号の効きは、声の混ぜ方（`beta`）を薄くすると縮む（`acting-punctuation/` は
0.7 で +39.3、`-stack/` は 0.3 で +25.4 Hz）。**床（0.0）まで降ろすと消えるのか**、
`？` も同じか。同じ台本を 4 段とも焼き直して、段の間の比較を内部で閉じた。
行 `明日、また来るね` の末尾 4 通り（`。` / `？` / `！` / なし）× `beta` 4 段
（0.0 / 0.3 / 0.5 / 0.7）× seed 5 = 80 本。ほかの欄は共通
（neutral・moderate・speed natural・pitch natural・delivery controlled・breathiness none）。

## 読み方

- **`！` の効きは、演技の層が作っている。** 床で **−1.2 Hz（2/5）＝ 0**、
  0.3 以上では **+19.9〜+42.2 Hz（どの段も 5/5）**。段が深いほど大きく、
  **0.0 と 0.3 のあいだで立ち上がる**（0.3 → 0.5 は横ばい +20.3 → +19.9）。
- **`？` は、床でも残る**（+13.1・5/5）。ただし**段を上げても伸びない**——
  0.5 では +2.6 で、**seed 3 の 1 本だけ −22.1**（残る 4 本は +1.7〜+13.5）。
  **`？` の効きは `beta` に依らない**（どの段でも 4〜5/5 で正・幅は 10〜21 Hz）。
  **地の読み（モデル自身）が疑問の上がりを作っている。**
  音素列は 4 通りとも末尾の記号だけが違う（`ne.` / `ne?` / `ne!` / `ne`）ので、
  差はモデルに記号がどう読まれたかの差。
- **床では「なし」がいちばん高い**（+19.1・5/5）。ただしこの行だけ **1.57 秒**で、
  句点ありの 2.25 秒より 0.7 秒短い。**終わりの記号が無いと、モデルは文を
  途中で切る**——高さの差は長さの差と切り離せない（floor の `。` との比較は
  この点で交絡している）。0.3 以上では差が消える（−1.9・+2.4・−1.5）。
- **0.7 の値は、`acting-punctuation-pitch/` の natural と同じ**（290.3 → 332.4）。
  同じ台本・同じ seed なので、別に焼いても同じ値になる。
  ⚠️ `acting-punctuation/` の +39.3 とは違う——あちらは Spec が別
  （`llm-specs.json` の none＝強度 0.5）で、この台本は moderate。**段の中だけで比べること。**

⚠️ 1 行・1 声・neutral だけ・seed 5 本。`beta` は 0.0 / 0.3 / 0.5 / 0.7 の 4 段だけ。
