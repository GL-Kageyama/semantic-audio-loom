# 作品の台詞に `！` を書いたら、声は動くか

`drama/script.yaml` の強い 3 行を、**そのまま（文末 `。`）**と**文末だけ `！`**にして
焼いた（3 行 × 2 記号 × seed 3 = 18 本）。感情・強度・声量・速さ・`delivery` は台本の
まま、seed は 1〜3、beta 0.7（作品と同じ）。

| 台本の行 | 欄 | `。` | `！` | `！` − `。` |
| --- | --- | --- | --- | --- |
| s31「なんで。なんで、そういうこと、平気で言うの」 | anger / strong / loud / fast / aggressive | 293.0 Hz | 308.5 | **+15.5**（3/3・+3.4〜+28.7） |
| s28「やめて。そういうの、やめて」 | fear / strong / normal / fast / desperate | 310.7 | 342.9 | **+32.2**（3/3・+25.0〜+38.8） |
| s63「まだ、話したい」 | sadness / strong / normal / slow / desperate | 281.9 | 341.3 | **+59.5**（3/3・+2.5〜+88.6） |

## 読み

- **作品の台詞でも、`！` は効く**（9/9 で正）。欄を 1 つも変えずに、文末の字を替えるだけで
  高い声になる。**演技の中身ではなく、書き方で動く**。
- **効きの幅は行の形で決まる**。いちばん大きい s63（8 文字・途中の句点なし）は +59.5、
  いちばん小さい s31 は **+15.5**——s31 は**途中に句点を 2 つ持つ**長い行で、9 文字で
  途中に句点を置くと +14.6 になるという測り（`acting-punctuation-period/`）と揃う。
  **短い行ほど、強く出る。**
- ⚠️ seed 3 本では幅が広い（s63 は +2.5〜+88.6）。**向きは 9/9 で揃うが、1 本ずつの
  大きさは seed で 2 倍以上動く**（seed の揺れは 84.6〜92.7 Hz・`REPORT.md`）。
  行ごとの値は `probe.tsv`。
- 長さは `！` で 0.00〜0.28 秒縮む（s63 はほぼ同じ・s31 は 0.28 秒短い）。
