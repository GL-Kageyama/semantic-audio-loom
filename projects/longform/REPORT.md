# 長尺ラン — 何が分かったか

生成→測定→修理のループを回し、5 分級の音を 2 本作る過程で、このエンジンの
「演技がどこまで届くか」を測った記録。数はすべてこの Mac の実測。

## 答え

**狙った向きに頼れるのは、時間と、文末の記号だけ。感情と強度は声の高さを確かに
動かすが、seed の揺れ（f0 で 84.6 Hz）よりは小さい。`！` は +39.3 Hz（5/5）で、
感情の語より大きく、seed の揺れの半分。演技はノブで出す。**

1. 既定の設定（`beta` 0.7）では、感情の一文・強度・抑揚を変えても、**seed を替えた
   ときほどには動かない**。ただし**同じ seed どうしで比べれば動いている**——10 感情は
   どれも f0 が 5/5 で基準線より高く（+4〜+26 Hz・guilt だけ 4/5）、強度は strong が
   subtle より 5/5 で高い（怒り +3.0〜+11.2・喜び +3.0〜+14.1・悲しみ +13.7〜+20.1 Hz）。
   **動くが、seed の振れ幅（f0 で 84.6 Hz）より小さい。** 狙った向きに頼れるのは
   依然として速さ（早口 5/5・間 5/5）と、文末の記号（`？` +16.3・`！` +39.3 Hz・5/5）。
2. `beta` を 0.3 まで下げると分かれる。seed の揺れが f0 で 29 → 12 Hz に縮み、
   高覚醒（喜び・怒り）と低覚醒（無表情・悲しみ）は重ならない。強度も f0 で出る（+20〜+45 Hz）。
   **効きの比（感情の幅 ÷ seed の幅）で見ると、0.7 で 0.27・0.5 で 0.82・0.3 で 2.1、
   0.0 で 12.9**——**seed を追い越すのは 0.5 と 0.3 のあいだ**。
   0.3 より下にも幅はあり、**0.0 で分かれは最大（+88 Hz）・seed の揺れはほぼ 0**。
   その代わり**声の中の起伏と間が縮む**（作品の段で間 0.220 → 0.127・抑揚 8.40 → 7.30
   半音）。**声そのもの（スペクトルの包み）は参照から離れない。**
   作品の段では、床は二人の声の高さも同じにする（人物差 −8.5 → +0.1 Hz）——**一人の
   演技の上限であって、二人芝居の上限ではない。**
3. 代償は**声の状態**（高さ・起伏・間・速さ）。**声質はほとんど動かない**——有声
   フレームで測ると、スペクトルの包みは beta 0.7 で 2.69 dB・0.0 で 1.80 dB と、
   むしろ参照に近づく（動き 0.89 dB は、参照どうしの最小差 1.22 dB より小さい）。
   演技は「声色を変えずに気持ちだけ乗せる」ものではないが、**声色が変わるとも言えない**。
4. 意味の写像ではない。悲しみを強めても f0 は上がる。11 の感情の名前は **4 つの音の
   群れ**に畳まれる（低い・中くらい・高い＋guilt だけ別）。高い群れの anger・confidence・
   fear・excitement・joy は seed の幅が重なって分かれない。分かるのは名前ではなく
   **覚醒と張り出しの段**まで。
5. 作品の側では、差は生成でなく設計で作る（声量は `gain_db`・間は `pause_before`・
   人物は帯域・下地は ducking）。
6. 声の中身を決めるのは `alpha`（`alpha × 予測 + (1−alpha) × 参照`）。上げるほど参照から
   離れ、下げるほど近づく（床で 2.64 → 1.61 dB）。既定の 0.35 は 65% が参照。
   だが 0 でも参照の録音とは同じ包絡にならない（1.61 dB は、真白とニジの参照の差
   1.22 dB と同じ大きさ）。`pitch` は音程を戻す（257 → 277 Hz。参照は 297 Hz）が、
   包絡は 1.69 → 1.13 dB で動かない。作品 89 本では上下は開く（人物差 +0.1 → −13.4 Hz・
   隣と比べて 21/42 → 31/42）が、**`very_low` が真白の台詞を 3 割短くして尺が門を割る**
   （339.1 → 291.0 秒）。
7. 感情の外では、速さと演技の型（delivery）が動く。声量は量を動かさない（ミックスの
   利得の仕事）。息は散文に載っていなかったのを直したが、まだ弱い。
   床（beta 0.0）では速さは同じだけ動くが、**delivery の幅は 45 → 25 Hz に縮む**。
   下げれば全部が伸びるわけではない。
8. 同じ seed でも、最後のビットまでは同じにならない（差は −64〜−65 dB・長さ同一）。
   別プロセスで 6 回作ると 2 種に割れるが、**`act_probe` の 14 欄は全部同じ**。
   **測った結論は動かない。md5 での同一性検査だけが使えない。** ただし
   **1 つのプロセスの中でも割れることがある**（25 本をまとめて焼いて seed 1 本だけ
   2 種・`f0_end_st_s` が 0.25 半音動いた）。md5 はどこでも当てにしない。
9. 強度は、**5 つの語に対して 2 段しかない**。跳ねるのは moderate → strong の 1 か所で、
   上端（overwhelming）は怒り・喜びで伸びず、**悲しみでは強さより低い**。真ん中が
   動かないのは、そこに散文が無いからだけでなく、**感情ごとに飽和点が違う**から。
   **「抑える」は抑える動作にならない**（語を足せば上がる。強さを主張する語ほど大きい）。
   耳で確かめる見本：[`examples/longform-intensity/`](../../examples/longform-intensity/)
   （1:03）。
10. **台詞の裏の意味（subtext）は、そのままでは声に届かない。** `--resolve rule` は
    rule が Spec へ写すが Provider の散文が読まないので、5 通り × seed 5 の 25 本で
    **音が同じ**（seed 1・2・4・5 は 5 本とも md5 一致）。`--resolve llm` は 5 通りを
    5 通りの散文へ変えるが、声を動かすのは変換後の `emotion.intensity` が 0.40 の
    境をまたいだときだけ（**+6.9 Hz・5/5**）。**抑揚語（neutral ↔ wavering）は
    +1.0 Hz・2/5 で、3 本は差 0.0 Hz。**「subtext を抑揚語へ変換して初めて乗る」の
    前半は正しく、後半（抑揚語 → 声）がこのモデルでは効かない
    （[`projects/longform/acting-subtext/`](acting-subtext/)、`docs/resolve.md`）。
    **表に無い自由文を足しても同じ**：同じ Spec の散文に「涙をこらえている」「返事が
    怖い」などを 1 文足した 25 本（[`projects/longform/acting-freetext/`](acting-freetext/)）で、
    f0 の差は **+2.1 Hz まで**（5/5 でも、seed の散らばり 91.3 Hz の 2%）。
    **上限は表ではなくモデルの側にある。**
11. **間（`prosody.pauses`）は生成の側では作れない。** LLM は「明日のあと 0.3 秒」と
    書いてくるが散文に入らず、台詞の読点で代用もできない
    （[`projects/longform/acting-pauses/`](acting-pauses/)・15 本：読点 2 個で
    **+0.005 秒**・3 個では **−0.195 秒**でむしろ縮む）。**間は台本の
    `pause_before` と組み立て（`assemble.py`）で作る**——既存の 2 作品はそうしている。
12. **台詞の字面で動くのは、記号（読点・文末）だけ。表記は動かない。** 同じ 1 行の
    最後を `。` / `？` / `！` / なしに替えた 20 本
    （[`projects/longform/acting-punctuation/`](acting-punctuation/)）で、
    f0 は（1 本ごとの f0 中央値を 5 本で平均して）`？` が **+16.3 Hz**・`！` が
    **+39.3 Hz**（どちらも 5/5）。
    **語尾だけではない**（`！` は声の前半 +36〜+50・後半 +8〜+58 Hz・5 本とも両方上がる）。
    句点を外すと語尾の傾きが +4.5 → **−21.5 半音/秒**（0/5）。長さは 0.16〜0.18 秒
    **縮む**ので、句読点は間ではなく高さのノブ。**10 感情の最大（+26 Hz）より強く、
    表に無い散文（+2.1 Hz）の 8 倍（`？`）〜19 倍（`！`）。**感情とは足し算になる**
    （`！` の効きは neutral で +39.5・joy で +40.3 Hz、感情の効きは `。` で +16.6・
    `！` で +17.4 Hz・すべて 5/5。**感情を 6 つに広げても同じ**——`！` は +35.1〜
    +40.7 Hz・18/18。**sadness + `！`（337.7 Hz）は neutral + `！`（338.0）と同じ高さ**
    で、`。` のままの sadness より 35 Hz 高い・[`acting-mark-emotion5/`](acting-mark-emotion5/)・
    36 本）。**`pitch` と掛けても消えない**（very_low +38.8・
    natural +42.2・high +47.4 Hz・15/15。`pitch` の側は neutral で −13.5〜+9.0 Hz で、
    記号の 3〜5 分の 1）。**別の人物・別の行でも同じ向き**（ニジ「今、行くよ」で
    +78.8 Hz・語り手 +58.1 Hz・どちらも 5/5。大きさは行と声で変わる）。**beta 0.3
    では +25.4 Hz（5/5）に縮む**。**床（beta 0.0）まで降ろすと `！` だけが消える**
    （−1.2 Hz・2/5）——`？` は **+13.1 Hz（5/5）**で残る。音素列は末尾の記号しか
    違わない（`ne.` / `ne?` / `ne!` / `ne`）のに、`！` は 0.0 で −1.2・0.3 で +20.3・
    0.5 で +19.9・0.7 で +42.2 と**床を出たところで立ち上がる**。`？` は 0.0 で
    +13.1・0.3 以降 +2.6 / +10.7 / +21.0 で、**段に依らず残る**（0.5 は seed 3 の
    1 本が −22.1 で平均を下げる）。
    **`！` の効きは演技の層が作り、`？` は地の読みが作っている**
    （[`acting-punctuation-floor/`](acting-punctuation-floor/)・80 本）。**行 3 つ ×
    声 2 つでも同じ向き**（0.7 で +39.0〜+95.4 Hz・6/6、床では **+7.2 Hz 以下**、
    正だった 4 組は 0.7 の 3.6〜10.9%・
    [`acting-floor-mark-lines/`](acting-floor-mark-lines/)・72 本）。**声の器は動かない**
    ——`。` と `！` の包絡の距離は 1.19 dB（中央）で、同じ `。` の seed 差
    0.93〜1.61 dB の中にある。記号が変えるのは高さと速さだけで、声そのものではない。
    **速さと掛けても消えない**（very_slow +30.4・natural +42.2・very_fast +57.1 Hz・
    15/15。**速さは長さを 4.20 → 2.36 秒動かすのに、f0 は −3.9〜+4.9 Hz しか
    動かさない**——記号は高さ、速さは長さのノブ・
    [`acting-punctuation-speed/`](acting-punctuation-speed/)・30 本）。**声を替えても同じ**
    （ニジでも +34.9〜+40.7 Hz・2 声で 18/18、速さ自身は −4.8/+8.2 Hz。長さは声に依らず
    3.9 → 2.1 秒・[`acting-speed-voices/`](acting-speed-voices/)・36 本）。**幅は行の形でも縮む**——同じ声・同じ Spec で
    9 文字 +39.3・14 文字 +43.2・24 文字 +15.0 Hz。**途中に句点を 1 つ入れると、
    9 文字でも +14.6 Hz まで落ちる**（24 文字で途中の句点を読点に替えると +26.4・
    すべて 5/5）。**句点がある行は長さが違っても揃い（+14.6〜+15.0）、句点のない行は
    長さで縮む（+39.3〜+26.4）**——途中で文が切れることが先で、長さは後
    （[`acting-punctuation-long/`](acting-punctuation-long/)）。**語尾に閉じて
    いない**（有声の前半も +13.7〜+14.5 Hz 上がる）。
    **記号を重ねても足し算にならない**（`？！` は `！` 単独と同じ +15.9 / +15.0 Hz）。
    **作品の台詞でも効く**（演劇の `intensity: strong` 9 行を文末だけ `！` にした
    54 本・27/27：+15.5〜+120.2 Hz。**ひとことの行がいちばん大きい**（「ニジ」+120.2・
    「まだ、話したい」+59.5）・**長い行はいちばん小さい**（+15.5）。ただし句点の数では
    説明できない（同じ 2 句点の s30 は +52.9）・[`acting-drama-mark/`](acting-drama-mark/)）。
    **解説の語りでも効く**（本物の語り 6 行・15〜38 文字・すべて `calm`・60 本：
    +21.5〜+49.1・平均 **+32.4**・6 行すべて正・30/30・
    [`acting-explainer-mark/`](acting-explainer-mark/)）。
    **強度が弱い行でも効く**（`subtle` / `moderate` の 12 行・120 本：12 行すべての
    平均が正・`subtle` の平均 +96.4・`moderate` の平均 +70.1。強い 9 行の平均 +55.0 と
    比べて小さいとは言えない・[`acting-drama-mark-weak/`](acting-drama-mark-weak/)）。
    **`…` は間を作らない**。文末の `…` は文字ごと消され、`なし` と同じ音になる
    （seed 4・5 は md5 まで一致・[`acting-punctuation-ellipsis/`](acting-punctuation-ellipsis/)）。
    途中の `…` は `、` に置き換わるので、`明日、……また来るね` は
    「明日、、また来るね」になり、**行はむしろ 0.85 秒縮む**（2.918 → 2.073 秒・0/5・
    無音率 0.315 → 0.195・[`acting-punctuation-ellipsis-mid/`](acting-punctuation-ellipsis-mid/)）。
    **言いよどみはこの字では作れない**（間は `pause_before`、語尾は `。` を外して作る）。
    耳で確かめる見本：[`examples/longform-ellipsis/`](../../examples/longform-ellipsis/)（0:34）。
    ——欄の効きとは逆向き。⚠️ **既存の 2 作品はこのノブをほぼ使って
    いない**（演劇 89 行中 88 行・解説 48 行すべてが「。」で終わる）。耳で確かめる見本：
    [`examples/longform-punctuation/`](../../examples/longform-punctuation/)（0:46）。
    **途中に置いても効く**：台本の 18 文字の行（y06）で、2 つ目の読点を `！` に替えると
    **+23.1 Hz**（5/5・文末は +36.8）・`。` に替えると **−3.6**（1/5）。**両方に置くと
    +61.1**（5/5・ほぼ足し算）。長さは 4.26 → 4.37 秒（途中の `。` は 4.51）
    （[`acting-punctuation-mid-exclaim/`](acting-punctuation-mid-exclaim/)）。
    **置く行を選ぶ**。`！` を配るほど山は低くなる（場面 13 行のうち s67 と次点の差：
    0 行 68.0 → 強い 3 行 1.0 → 全部 12 行 −43.3 Hz・seed 5・
    [`drama-scene-mark-seed/`](drama-scene-mark-seed/)・
    [`drama-scene-mark-selective/`](drama-scene-mark-selective/)）。**外すのも同じ幅**で、
    s67 の `！` を `。` に戻すと 391.0 → 288.0 Hz（−103.0）。**移したいなら、もとの山から
    記号を外す**——s68 に足すだけは 4/5 でしか 1 位にならないが、外すと 5/5 で入れ替わる
    （195 本・[`drama-scene-mark-relocate/`](drama-scene-mark-relocate/)）。
    **表記は 1 ビットも変えない**：`また` / `マタ` / `又` は md5 まで同じ
    （[`projects/longform/acting-notation/`](acting-notation/)）。**読点を 1 個足すと
    f0 −17.0 Hz**（4/5）で、長さは +0.03 秒——**読点も高さの印で、間ではない。**

参照音声との包絡の距離 dB）。詳しい節は右端。

## 演技はどこまで動くか（P1・P2）

### 計器

`bin/act_probe.py` を足した。f0（2 段の追跡・有声確率 0.3 以上）、抑揚（半音）、
語尾の傾き（最後の 100 ms 以上の連続区間）、速さ（拍/秒、分母は鳴っている時間）、
間の比、張り（有声区間のエネルギー）、立ち上がり（ms）。

計器そのものの欠陥を 3 つ直してから測っている（減衰尾を有声と数えていた・間を
またぐ直線当て・速さの分母）。**音の前に計器を疑う**のが先。

声質の計器は 2 つ（`measure_timbre.py` の有声フレーム MFCC・`measure_envelope.py` の
LPC 包絡）。前者も後から欠陥が見つかって直した（「計器の欠陥」の節）。

### 11 感情（moderate・seed 5）

`schemas/performance_direction.schema.json` の enum 11 語のうち neutral 以外の 10 感情を
seed 1〜5 で振った（85 本＝10 感情 ×5 ＋ 基準線 5 ＋ 強度 30）。判定は枠外 10 種と同じ
「基準線の 5 seed 中央値に対して、感情の 5 seed が全部同じ側か（5/5 か 0/5）」。
加えて、その差が**基準線そのものの幅**（max−min）を超えているかも見る。

基準線（neutral moderate・5 seed）: 長さ 2.97 s（幅 0.50）・f0 290.4 Hz（幅 84.6）・
抑揚 8.00 半音（幅 2.10）・速さ 5.20 拍/秒（幅 1.10）・張り −14.20 dB（幅 2.70）。

**10 感情のどれも、8 指標のいずれでも基準線から 5/5 で分かれない。**
5/5 に届いた少数（guilt の長さ +0.15 s など）も、差は基準線の幅（0.50 s）の中。
感情の差は種の中のばらつき（f0 ±30 Hz）に完全に含まれる。

⚠️ **但し書き（`acting/reanalyze_seeds.py`）。この判定は seed をそろえていない。**
比べているのは「感情の 5 seed」対「基準線の**中央値**」で、seed 5 は基準線でも
241.4 Hz まで下がるので、感情の seed 5（喜び 258.7 Hz）は中央値 290.4 を下回り
「4/5」に落ちる。**同じ seed どうしで比べ直すと、10 感情はどれも 5/5 で f0 が
基準線より高い**（fear +25.5・joy +23.9・anger +19.7・excitement +18.0・confidence
+15.1・anxiety +14.9・calm +7.2・loneliness +6.4・guilt +5.1・sadness +4.2 Hz）。
**強度も 5/5 で効く**（怒り +3.0〜+11.2・喜び +3.0〜+14.1・悲しみ +13.7〜+20.1 Hz）。

**どちらも本当で、言い方が違う。** 差は**検出できる**（seed をブロックした F は
f0 29.95・p 1.3e-23）が、**seed を替えたときの振れ幅（84.6 Hz）より小さい**。
「感情は音に乗らない」ではなく「**乗るが、seed の揺れほどではない**」。

**強度（subtle 0.25 → strong 0.75）も分かれない。** 同じ seed どうしの差の符号が
5/5 で揃ったのは f0 だけ（anger +3.6・joy +12.9・sadness +20.1 Hz）で、いずれも
基準線の幅 84.6 Hz より小さい。言葉を強めても、音は同じ幅の中で揺れるだけ。

⚠️ 上の括弧は**中央値の 1 本**（anger +3.6・joy +12.9・sadness +20.1）で、5 seed の
幅はもっと広い：anger +3.0〜+11.2・joy +3.0〜+14.1・**sadness +13.7〜+20.1 Hz**。
**強度は 3 感情すべてで 5/5 そろって上がる**——「分かれない」ではなく「seed の振れ
（84.6 Hz）より小さい」。**強度のほうが感情より効く**（悲しみの strong は neutral から
+22.5 Hz で、sadness 単体の +4.2 Hz より大きい）。

⚠️ この 85 本は**散文が違う**（`params.yaml` の emotion が別、`_spec_prompt` が
感情ごとに別の一文を組む）。言葉が届いていないのではなく、**届いた先で動かない**。
感情の一文は `Kotodama_Prompter` を通って 128 次元の prosody ベクトルになり、
参照音声の timbre と `alpha=0.35 / beta=0.7` で混ぜられる。疑うべきは言葉の側でなく
**混ぜるノブ**の側——そこで beta を振った（次節）。

### ノブ（beta）を振る — 演技が出る場所

感情の言葉は届いているのに音が動かない（前節）。ならば混ぜる割合を疑う。
`beta` は「プロンプト由来の口調をどれだけ混ぜるか」のノブで、既定は 0.7。
同じ台詞・同じ参照音声（mashiro）・同じ seed で、**beta だけ** 0.7 / 0.5 / 0.3 に振った
（alpha 0.35 固定・4 感情 × seed 1〜5 × 3 段＝60 本）。

| beta | neutral | anger | joy | sadness | 5/5 で分かれた指標（neutral との差） |
| --- | --- | --- | --- | --- | --- |
| 0.7（既定） | 290±29 | 311±34 | 315±33 | 292±31 | sadness の速さだけ |
| 0.5 | 271±20 | 322±23 | 324±19 | 292±22 | anger 高さ +51.2・joy 高さ +53.1・sadness 長さ +0.45 ほか |
| 0.3 | **257±12** | **320±11** | **326±10** | **284±12** | anger 高さ +63.2・抑揚 +1.3・間 +0.13・張り −3.6 ほか |

（f0 は Hz の中央値±標準偏差。5 seed。）

- **beta を下げると、まず seed の揺れが縮む**（f0 の標準偏差 29 → 12 Hz）。その中で
  感情の差が残るので、5/5 で分かれる。
- beta 0.3 の f0 の範囲は neutral 252–280 / sadness 269–299 / anger 302–334 / joy 308–339。
  **高覚醒（anger・joy）と低覚醒（neutral・sadness）は重ならないが、anger と joy は重なる。**
  分かれるのは感情の名前ではなく**覚醒の段**。
- 言葉の向きは意味どおりとは限らない。sadness の文は「低く、柔らかく、遅く」だが、
  beta 0.3 の f0 は neutral より **+26.6 Hz 高い**。感情の一文は意味の写像ではなく
  **声全体を寄せる方向ベクトル**として効いている。
- beta は neutral 自身も動かす（290 → 257 Hz）。「演技だけを足すノブ」ではなく、
  **プロンプト全体への寄り具合**を変えるノブ。

**seed をブロックして測ると、beta は「効きの比」を動かすノブだと分かる**
（`acting/beta_blocked.py`・4 感情 × seed 1〜5・seed ごとの感情の幅と、感情ごとの seed の幅）。

| beta | F 感情 | η² 感情 | η² seed | 感情の幅 | seed の幅 |
| --- | --- | --- | --- | --- | --- |
| 0.7 | 76.63（df 3,12・p 4e-08） | 0.09 | 0.90 | 23.9 Hz | 89.8 Hz |
| 0.5 | 44.62（df 3,12・p 9e-07） | 0.45 | 0.51 | 46.7 Hz | 57.0 Hz |
| 0.3 | 192.79（df 3,12・p 2e-10） | **0.83** | 0.15 | 62.2 Hz | 30.2 Hz |
| 0.2 | 103.31（df 3,6） | 0.92 | 0.06 | 75.2 Hz | 20.3 Hz |
| 0.1 | 155.72（df 3,6） | 0.96 | 0.02 | 88.4 Hz | 13.1 Hz |
| 0.0 | 276.50（df 3,6） | **0.99** | 0.01 | **92.8 Hz** | **7.2 Hz** |

（0.7〜0.3 は seed 5 本、0.2〜0.0 は seed 3 本なので F は段をまたいで比べない。
幅と η² で読む。）

- **0.7 でも感情は効いている**（F 76.63）。ただ **seed の幅（89.8 Hz）の 4 分の 1 弱**
  なので、seed を 1 本ずつ眺めると見えない。
- **0.3 で逆転する**（感情 62.2 Hz・seed 30.2 Hz）。**交差点は 0.5 と 0.3 のあいだ。**
- **下へ行くほど一方向に伸びる**：感情の幅 23.9 → 46.7 → 62.2 → 75.2 → 88.4 → 92.8 Hz、
  seed の幅 89.8 → 57.0 → 30.2 → 20.3 → 13.1 → 7.2 Hz。**0.0 で感情が声をほぼ決める。**
- 抑揚・張りも同じ向き（抑揚の η² 感情 0.05 → 0.19 → 0.55、張り 0.04 → 0.36 → 0.85）。
  速さだけはどの beta でも分かれない（F 0.31 / 3.13 / 2.72）。


### 計器の欠陥：「クリップ全体の MFCC 平均」は無音の割合を測っていた

ここまでの距離は、はじめ `measure_timbre.py` が**クリップ全体のフレーム平均**で出していた。
これが声質の距離になっていない。**同じ音に無音を足すだけで距離が伸びる**からだ
（`check_timbre_metric.py`・真白の参照に無音を継ぎ足しただけ）:

| 足した無音 | 有声フレームで測る（修正後） | クリップ全体で測る（旧） |
| --- | --- | --- |
| 0.0 s | 0.00 | 0.00 |
| 0.5 s | 0.00 | 21.78 |
| 1.0 s | 0.00 | 39.84 |
| 2.0 s | 0.00 | 68.06 |

声は 1 ビットも変わっていないのに、旧い計器は 68 も離れたと言う。beta を下げると
**間が減り、有声の割合が上がる**（作品の段で 0.311 → 0.459）ので、旧い計器は
「演技が変わった」を「声質が変わった」と報告していた。

直した計器は 2 つ。`measure_timbre.py` は**鳴っているフレームだけ**で平均する
（最大フレームの 5% を超えるフレーム）。`measure_envelope.py` は**LPC 包絡**
（声道の共鳴の形）を測るので、倍音の間隔＝pitch に引っ張られない。

修正後の掃引（`acting-beta-*/` の 4 感情 × seed 3＝12 本の中央値）:

| beta | 有声フレームの MFCC | LPC 包絡（dB） | 旧・クリップ全体の MFCC |
| --- | --- | --- | --- |
| 0.7 | 60.9 | 2.69 | 22.2 |
| 0.5 | 59.3 | 2.35 | 31.0 |
| 0.3 | 55.9 | 1.98 | 43.3 |
| 0.2 | 59.0 | 1.94 | 49.4 |
| 0.1 | 53.6 | 1.80 | 58.8 |
| 0.0 | 58.0 | 1.80 | 65.8 |

**旧い数字（22 → 66）の単調な伸びは計器の作った像。** 有声フレームでは 54〜61 で
動かず、包絡は 2.69 → 1.80 dB と**むしろ少し近づく**（差 0.89 dB は、参照どうしの
いちばん近い組＝真白↔ニジの 1.22 dB より小さい）。**演技は声を変えて出ている、とは
言えない。変わるのは声の状態。**

- 3 段ともクリップ 0・ピーク 0.95。

### beta をさらに下げる（0.2・0.1・0.0）— 演技は伸び、声は離れない

0.3 より下にまだ幅があるかを測った（`acting-beta-low/`。alpha 0.35 固定・4 感情 ×
seed 1〜3 × 3 段＝36 本。0.3 以上は既存の 60 本から seed 1〜3 を同じ条件で抜いた）。

| beta | neutral | anger | joy | anger − neutral | seed の揺れ（f0 の SD） | 参照との包絡の距離（dB・12 本の中央値） |
| --- | --- | --- | --- | --- | --- | --- |
| 0.7（既定） | 290.4 | 311.2 | 314.9 | +20.8 | 20.6 | 2.69 |
| 0.5 | 271.0 | 322.2 | 324.1 | +51.2 | 14.5 | 2.35 |
| 0.3 | 257.2 | 320.4 | 331.7 | +63.2 | 8.8 | 1.98 |
| 0.2 | 252.8 | 318.5 | 333.6 | +65.7 | 8.5 | 1.94 |
| 0.1 | 237.2 | 322.2 | 329.8 | +85.0 | 5.7 | 1.80 |
| 0.0 | 240.0 | 327.8 | 333.6 | +87.8 | 3.0 | 1.80 |

- **分かれは 0.0 まで伸びる**（+21 → +88 Hz）。同時に **seed の揺れが消える**
  （20.6 → 3.0）。beta 0.0 の anger は seed 1〜3 が 327.8 / 327.9 / 327.8 Hz で、
  ほぼ同じ音になる。**演技がプロンプトの文面そのものになり、seed はもう演技に効かない。**
- **声そのものは離れない。** 包絡の距離は 1.98 → 1.80 dB と少し縮む（0.18 dB は
  参照どうしの最小差 1.22 dB より小さい）。分かれの伸びは 0.3 → 0.2 でほぼ止まり
  （+2.5 Hz）、0.2 → 0.1 で一段跳ぶ（+19.3 Hz）。つまり **0.2 は 0.3 とほぼ同じ演技を、
  0.1 は跳ねた演技を、どちらも同じ声で**やっている。
- 抑揚（7.8〜8.4 st）・速さ・間・張り幅は 0.0〜0.7 のあいだで崩れない。
  測れる指標の範囲では「壊れる」兆候は出ていない（耳で確かめてはいない）。
- beta 0.0 は prosody が全部 Kotodama プロンプト由来になる点。**この線より下は
  「プロンプトに書いていないことは起きない」世界**なので、演技の下限というより
  プロンプトの文面の限界が見えている。

### 強度（subtle / strong）は beta 0.3 で分かれる

beta 0.7 では subtle 0.25 と strong 0.75 が揺れに埋もれた（前々節）。同じ 3 感情を
beta 0.3 で振り直した（30 本・seed 1〜5）。同じ seed どうしの差の符号が 5/5 揃った指標:

| 感情 | 高さ | 長さ | 語尾 | 張り |
| --- | --- | --- | --- | --- |
| anger | **+31.2 Hz** | +0.28 s | +2.05 半音/秒 | −1.90 dB |
| joy | **+20.2 Hz** | +0.20 s | +2.24 半音/秒 | −3.80 dB |
| sadness | **+45.2 Hz** | — | — | −1.50 dB |

**強度は「高さ」で出る。** 3 感情とも strong が subtle より高い（+20〜+45 Hz）。
beta 0.3 の種の中の幅は 12 Hz 程度なので、これは幅の外。

⚠️ **張り（energy_median）が strong で下がるのは計器の交絡**。strong は長さも伸びるので
無音フレームが増え、中央値が下がる。張りの低下としては読まない。

⚠️ **意味の向きとは一致しない**。sadness の strong は「感情が強い」のに f0 が +45 Hz 上がる。
感情の名前も強度も、モデルには**声全体の寄せ先**として効いており、「悲しければ低い声」の
ような意味の写像ではない。

### 強度の語は 5 段あるが、段の順にはならない（90 本・beta 0.3 と 0.0）

Direction の強度は none / subtle / moderate / strong / overwhelming の 5 語。
3 感情 × 5 語 × seed 1〜3 × beta 0.3 / 0.0 で振った（`acting-intensity/`）。f0 中央値:

| 感情 | beta | none | subtle | moderate | strong | overwhelming |
| --- | --- | --- | --- | --- | --- | --- |
| neutral | 0.3 | 257.2 | 275.7 | 257.2 | 283.8 | 262.5 |
| neutral | 0.0 | 240.0 | 255.7 | 240.0 | 267.9 | 260.2 |
| anger | 0.3 | 320.4 | 326.0 | 320.4 | 347.3 | 349.4 |
| anger | 0.0 | 327.8 | 331.7 | 327.8 | **376.6** | 365.9 |
| joy | 0.3 | 331.7 | 328.8 | 331.7 | 339.4 | 341.4 |
| joy | 0.0 | 333.6 | 329.7 | 333.6 | 372.3 | **376.6** |

- **none と moderate は同じ音**（どの seed でも値が一致）。散文では両方とも一言も
  足さないため。5 語は実質 **4 段（none = moderate / subtle / strong / overwhelming）**。
- **段の順にはならない。** neutral では overwhelming（262.5）が strong（283.8）より
  低い（3 seed とも）。anger は floor で strong が overwhelming より高い（376.6 対
  365.9・3/3）。joy は逆に overwhelming が上（3/3）。**「max の語」は感情によって
  別の向きに振れる。**
- 床（beta 0.0）では strong / overwhelming の振り幅が大きい（anger 327.8 → 376.6、
  joy 333.6 → 376.6）。**強度の語も、下げた側で強く出る。**

### 既定 0.7 でも、段は 2 つしかない（4 段 × 5 seed）

同じ 1 行・同じ人物・seed 1〜5・既定 beta 0.7 で 4 段を並べた
（`acting-intensity/`。subtle / moderate / strong は `acting-matrix/` の 30 本、
overwhelming は `acting-overwhelming-070/` の 15 本。基準線の f0 平均 290.3 Hz）。

| 感情 | subtle | moderate | strong | overwhelming |
| --- | --- | --- | --- | --- |
| anger | 312.6 | 310.0 | 320.0 | 320.7 |
| joy | 313.8 | 314.2 | 323.0 | 323.0 |
| sadness | 295.3 | 294.4 | 312.8 | **304.0** |

| 段の間 | anger | joy | sadness |
| --- | --- | --- | --- |
| subtle → moderate | −2.7 Hz（0/5） | +0.4 Hz（1/5・n.s.） | −0.8 Hz（1/5・n.s.） |
| moderate → strong | **+10.0 Hz（5/5）** | **+8.8 Hz（5/5）** | **+18.3 Hz（5/5）** |
| strong → overwhelming | +0.7 Hz（3/5・n.s.） | +0.0 Hz（3/5・n.s.） | **−8.8 Hz（0/5）** |

- **跳ねるのは moderate → strong の 1 か所。** subtle と moderate の差は ±3 Hz。
- **上端は伸びない。** anger・joy は strong と同じ高さ。**sadness は 5 seed とも下がる。**
  低い beta でも同じ向きで、しかも大きい（beta 0.3 で −27 Hz・3/3、
  `acting-intensity-sadness/`）。**「at its limit」の一言は、sadness では高さを下げる側に働く。**
- **高さだけではない。** moderate → strong で長さが anger +0.08 秒・joy +0.14 秒
  （5/5・p ≤ 0.016）、sadness で抑揚 +0.44 半音（5/5・p = 0.009）。energy・速さは動かない。

**真ん中が動かないのは、真ん中に文言が無いからか。** `_INTENSITY_PHRASES` は
0.40〜0.70 の帯に何も置かない（つまり moderate は「強度を言わない」）。そこへ
"the feeling is moderately strong" を差し込んで moderate だけを作り直した
（`acting-mod-phrase/`・15 本。原本は触らず、プロセスの中で表を差し替える）。

| 感情 | 差（文言あり − なし） | 同符号 | p |
| --- | --- | --- | --- |
| anger | +1.3 Hz | 4/5 | 0.028 |
| joy | +1.7 Hz | 4/5 | 0.072 |
| sadness | **+9.4 Hz** | 5/5 | 0.0015 |

**sadness だけ動く**（strong の +18.3 Hz の半分ほど）。**anger・joy は moderate で
ほぼ飽和していて、文言を足しても動かない。** 段が 2 つに見えるのは、文言が無いから
だけではなく、**感情ごとに飽和点が違う**から。

**「抑える」は、抑える動作にならない。** sadness の同じ帯に 3 つの文言を置いた
（`acting-sadness-heldback/`・`acting-sadness-open/`・seed 5 本ずつ）。

| --- | --- | --- | --- |

| the feeling is steady and open | 299.9 | +5.4 Hz | 5/5 |
| the feeling is moderately strong | 303.9 | **+9.4 Hz** | 5/5 |

**どの文言も高さを上げる。** 順は「どれだけ感情を主張しているか」の順で、
**抑制（held back）は下げない**。anger でも同じ文言で +3.6 Hz（5/5）。energy は
4 条件で ±0.5 dB（n.s.）。
**強度は「量」のノブで、「抑える」という動作のノブは無い**——演じ分けたいなら
`beta` を下げるか、`pitch`・`speed`・`delivery` を別に振るしかない。

**台詞を替えても形は同じ**（2 行目「そんなこと、ないよ。」で 4 段 × 3 感情 × seed 5・
`acting-intensity-line2/`）。真ん中は動かず（±2 Hz）、strong で跳ね（+17〜+25 Hz・5/5）、
**上端は 3 感情とも strong 以下**（−3.4〜−14.2 Hz）。**2 行 × 3 感情の 6 通りすべてで、
「最大」は強さを超えない**（−14.2〜+0.7 Hz）。ただし跳ね幅は seed に強く依り
（joy の 2 行目で +1.5〜+59 Hz）、5/5 でも t 検定は anger p = 0.17・joy p = 0.13。

**長い台詞では、跳ねる先が変わる**（`acting-longline/`・芝居の 1 行 24 文字・
4 段 × 3 感情 × seed 5・60 本）。3 秒の一言では moderate → strong は**中央値**で跳ねた
（+8.8〜+18.3 Hz）。長い行では、**3 感情とも抑揚の幅が広がる**
（+0.60/+0.78/+0.84 半音・すべて 5/5・p ≤ 0.01）のに対し、**中央値が動くのは sadness
だけ**（+13.2 Hz）。joy +0.7・anger +4.0 は n.s.。上端は同じで、sadness の overwhelming は
高さ −5.2 Hz・抑揚 −0.50 半音（どちらも 0/5）。長さ・energy・速さは動かない
（短い行で見えた長さ +0.08〜0.14 秒は再現しない）。
**強さは「高い声」ではなく「振れ幅の大きい声」。** 短い行では高さにしか出ようが
なかった、と読むのが正しい。

**声を替えても同じか（`acting-niji-intensity/`）。** 演劇のもう一人 niji は 42 本の
うち 41 本が subtle か moderate。niji の声で、niji が実際に使う 3 感情を測った。

### Direction の欄は、どれが段になるか

同じ手法（同じ行・同じ感情・seed 5 本・欄だけを振る）で 5 つの欄を並べた。

| 欄 | 語の数（測った数） | 声に届く段 | 測ったところ |
| --- | --- | --- | --- |
| `speed` | 5（5） | **5**（単調・1.74〜1.80 倍） | very_slow 4.39 → very_fast 2.44 秒・3 感情とも 5 seed すべてで順序が崩れない。f0 は両端で +14.8 Hz |
| `pitch` | 6（6） | **2〜3**（下だけ） | joy・controlled の 6 語 × seed 10（`acting-pitch-ladder/`）：very_low 299.0 / low 302.0（同じ段・p = 0.19）/ slightly_low 309.7 / natural 315.5 / slightly_high 312.9 / high 315.4 Hz。**上がる語は無い**（high は −0.1・slightly_high は −2.6）。neutral の声では high が +18.8 Hz 動いており、**上側は状態に依る** |
| `emotion` | 11（11） | 効く（**neutral より上へ +4〜+26 Hz**。だが**隣どうしは同じ声**） | 11 語 × seed 5（`acting-emotion-ladder/`）：fear 315.8 / joy 314.2 / anger 310.0 / excitement 308.2 / confidence 305.3 / anxiety 305.2 / calm 297.4 / loneliness 296.7 / guilt 295.4 / sadness 294.4 / neutral 290.3 Hz。neutral との対応のある差は 9/10 が 5/5（guilt だけ 3/5・p = 0.29）。**遠い語は離れる**（fear − sadness +21.3 Hz・5/5・p = 0.0001）が、**近い語は離れない**（fear − joy +1.6・3/5・p = 0.22、confidence − anxiety +0.1・1/5）。seed の散らばりは 64.6〜98.0 Hz |
| `intonation` | 5（5） | **ほぼ 0**（5 語の幅 7.7 Hz 対 seed の幅 74〜87 Hz） | 語尾の傾きの中央値は wavering 3.18 > neutral 2.71 > flat 2.11 > rising −0.35 > falling −1.64（`acting-inton-070/`） |
| `intensity` | 5（4） | **2** | subtle ≈ moderate、moderate → strong で跳ねる、上端は伸びない |
| `delivery` | 12（12） | **3** | 真ん中 8 語は ±4 Hz、aggressive +6.7・desperate +8.4、cold −9.4・flat −18.4 Hz |
| `breathiness` | 4（4） | **2**（幅 1.3 ポイント。0.3 では段にならない） | 有声の割合 0.276 → 0.263・高域の比 +10%（`acting-breath-070/`・`acting-breath-030/`） |
| `volume` | 5（5） | **0**（energy の段としては。shout だけ f0 +9.6・長さ +0.13 秒） | whisper と loud で energy 0.08 dB。ミックスの `VOLUME_GAIN` が 5 段作る |

（`delivery` は `acting-delivery/` と `acting-delivery2/`・`speed` は `acting-speed/` と
`acting-speed-emotions/`・`volume` は
`acting-volume/` と `acting-volume-shout/`。`intonation` は `acting-inton-070/` と
`acting-intonation2/`、および下の「語尾の抑揚は、beta を下げても分かれない」節。）

- **単調な 5 段になるのは `speed` だけ。** 5 seed それぞれで 5 語の長さの順序が完全に
  一致する。台本はこれを一番使っている（演劇の speed は slow 44・natural 31・fast 10・
  very_slow 4）。
- **その 5 段は、感情を替えても崩れない。** joy に anger と sadness を足した 3 感情 ×
  5 段 × seed 5 で、すべての seed が単調（各 5/5・段ごとの p ≤ 3.2e−04）。
  比は anger 1.79・sadness 1.74・joy 1.80 倍。**長い行（24 文字・5〜7 秒）でも
  1.75 倍・5/5 単調**（`acting-speed-longline/`）。**伸びるのは発話そのもので、間の割合は
  0.22〜0.32 のまま動かない。** 高さは短い行の両端だけで開く
  （5 段の平均 306.0 → 320.8 Hz・+14.8 Hz・seed 4/5・`acting-speed/`）——
  **長い行（24 文字）では動かない**（285.2 → 284.5 Hz・`acting-speed-longline/`）。
  `very_slow` は 4.2〜4.4 秒、`very_fast` は 2.4 秒——長さの差 2 秒は、
  5 本つないだ作品では間の設計に効く。
- **段は積み上がらない——ただし、上へ動かす型だけ。** `speed` を端まで振れば
  **`aggressive`** の差は消える（`acting-knob-stack/`）。速さの効きは delivery を替えても
  同じ（−1.95 / −1.88 秒・1.79 / 1.76 倍・0/5）だが、**aggressive − gentle の差は
  natural の +6.7 Hz から very_slow +0.7・very_fast −1.1 Hz へ縮む**
  （差の差 −1.84 Hz・5/5・p < 0.001）。
  **下へ動く `cold` / `flat` は端でも残る**（`acting-knob-stack-cold/`：cold −10.5 / −9.4 /
  −11.0、flat −16.5 / −18.4 / −21.4 Hz・交互作用は p ≥ 0.35）。
  **`pitch` を振ると aggressive の差は半分になる**（natural +6.8 → low +3.4 / high +2.1 Hz・
  中央値・`acting-knob-stack-pitch/`）。**消える型と消えない型がある。**
- **強い欄どうし（speed × pitch）も、足し算にならない**（`acting-knob-stack-speed-pitch/`・
  seed 10 本）。速さの高さの効きは pitch high で +5.9 Hz・natural で +4.3・
  **low で +0.5（p = 0.91）**。加算からのずれは −3.8 / +1.7 Hz で有意でない（p ≥ 0.35）。
  **長さだけは pitch が何であっても −0.62〜−0.76 秒・10/10 で動く。**
  この条件では `pitch` の `high` は −0.1 Hz で、**`low`（−13.5 Hz・9/10）だけが段になる。**
- **語の数と段の数が、まったく対応しない。** 12 語の欄（delivery）が 3 段、
  5 語の欄（volume）が 0 段、5 語の欄（speed）が 5 段。
- **感情の 11 語は「neutral より上」と「隣どうしは同じ」に分かれる**
  （`acting-emotion-ladder/`）。neutral との対応のある差は +4〜+26 Hz で 9/10 が 5/5 だが、
  **感情どうしでは遠い 2 語しか離れない**（fear − sadness +21.3 Hz・fear − joy +1.6・
  confidence − anxiety +0.1 Hz）。見本は
  [examples/longform-emotions/](../../examples/longform-emotions/)（75 秒・11 語）。
  **型を足しても離れない**（`acting-emotion-delivery/`・45 本）：fear − joy は gentle +2.8・
  cold +3.1 Hz で、**`aggressive` では −7.0 Hz（0/5・p = 0.015）と逆転する**。
  `aggressive` は neutral に効かず（+0.1）、**喜びだけを上げ（+6.7）・恐怖は下げる（−3.1）。**
  neutral からの差（+20〜+27 Hz）は、どの型でも 5/5 で残る。
- **breathiness は段になるが、幅が 1.3 ポイント。** 既定 0.7 で有声の割合が 5 seed とも
  同じ向きに下がり（0/5・p = 0.021）、高域の比が +10%。**beta 0.3 でも seed 5 本なら
  出る**（slight は有声 −2.8 ポイント・0/5、高域 +9.8%・**5/5・p = 0.0001**）が、
  **単調にならない**（none 0.403 → slight 0.375 → moderate 0.385 → heavy 0.411。
  heavy は f0 +16.9 Hz）。**段として使えるのは 0.7 のほう。** 囁き・息は、いまのところ
  欄では作れない（`volume` 0 段・`breathiness` 1.3 ポイント）。
- **強弱を演じさせたいなら speed と pitch。音量の強弱はミックス。**
  intensity の語を書き分けても、声は同じ段に留まる。

**直したこと：** Direction の intensity=none は 0.0 に解決されるが、散文では
「the feeling is faint」を足していた（none が faint になる）。0 では一言も足さないよう
直した。**欄が散文に載っているかを、Schema の列挙値ごとに比べる検査を足した**
（`test_every_enum_value_reaches_the_prompt`。二つの値が同じ文になる＝どちらかが
捨てられている、を検出する）。

### 語尾の抑揚は、beta を下げても分かれない

`prosody.intonation`（rising / flat / falling）を Direction から指定できるようにした
（rule Resolve が `neutral` 固定だった）。同じ台詞・同じ seed で 3 種 × 5 seed を
beta 0.7 と 0.3 で振った（60 本）。

| beta | rising | flat | falling | rising > falling の seed |
| --- | --- | --- | --- | --- |
| 0.7 | −0.35 | +2.11 | −1.64 | 3/5 |
| 0.3 | +2.16 | +1.26 | −0.17 | 2/5 |

（語尾の傾き・半音/秒の中央値。5 seed。）

beta 0.3 では中央値の並びは狙いどおり（rising > flat > falling）になるが、
**種ごとに見ると 2/5**。振れ幅（−19.3〜+16.8 半音/秒）が差（約 2 半音/秒）を飲む。
**抑揚の言葉も、この台詞・この参照音声では 1 本ずつでは聞き分けられない。**

床（beta 0.0）でも同じ掃引をした（15 本）。今度は**種ごとに 5/5 で順序が揃う**。

| beta | rising | flat | falling | rising > falling の seed |
| --- | --- | --- | --- | --- |
| 0.0 | **+14.73** | +14.14 | +13.78 | **5/5** |

ただし中身は「分かれた」ではない。**語尾はどの条件でも大きく上向き（+13.8〜+14.7）**で、
言葉による差は 0.95 半音/秒しかない（seed 3 は 14.32 対 14.29）。上向きの傾きは
プロンプトの文面のほうが決めていて、`intonation` の語はその上に小さく乗る。
語は中央の音高も動かす（rising 238.6 対 flat 248.5 Hz・seed 1/2/4/5）。
**床では順序が安定するが、差そのものは大きくならない。**

### 床の効き方は、台詞によって違う（60 本）

beta 0.3 で覚醒の分かれ方が残った 3 台詞と、語り手・ニジの参照音声を、床でも振った
（`acting-floor-lines/` 36 本・`acting-floor-refs/` 24 本）。anger − neutral（Hz）:

| 台詞 | beta 0.3 | beta 0.0 |
| --- | --- | --- |
| 明日、また来るね。 | +63.2 | **+87.8** |
| ちょっと、待ってよ。 | +23.1 | +20.7 |
| そんなこと、言わないでよ。 | +42.3 | +54.7 |

- **符号は 6/6（3 台詞 × anger/joy）で 3 seed とも揃う。** 分かれることは台詞に依らない。
- **大きさは台詞に依る。** 床が伸ばすのは 1 本目だけで、2 本目は 0.3 と変わらない
  （+23 → +21）。**「下げれば必ず強く分かれる」ではなく、その台詞が 0.3 でどれだけ
  分かれているかを、床は増幅するかしないか。**
- 参照音声が変わっても、床の分かれは同じ（narrator +85.5・niji +86.0・mashiro +87.8）。
  **声の誰かは関係なく、同じ prosody が乗っている。**

### alpha は「参照の量」ではなく「予測の量」だった（beta 0.3 / 0.0）

beta 0.3 で声が参照音声（`references/mashiro.wav`。f0 297 Hz）から離れているかを、
2 つのノブで試した（seed 1〜3・同じ台詞）。距離は包絡（dB・neutral 3 本の中央値）。
**alpha の式は `ref = alpha × 予測 + (1 − alpha) × 参照`** なので、上げると参照が減る。

| 振ったもの | 値 | neutral / anger / joy（Hz） | 参照との包絡の距離（neutral） | 分かれ方 |
| --- | --- | --- | --- | --- |
| alpha（48 本） | 0.20 | 262 / 324 / 332 | 1.55 | 3/3 |
| | 0.35 | 257 / 320 / 332 | 1.69 | 3/3 |
| | 0.50 | 260 / 315 / 330 | 1.85 | 3/3 |
| | 0.70 | 257 / 315 / 330 | 2.12 | 3/3 |
| pitch（36 本） | natural | 257 / 320 / 332 | 1.69 | 3/3 |
| | slightly_high | 266 / 319 / 326 | 1.86 | 3/3 |
| | high | 277 / 328 / 331 | 1.13 | 3/3 |

- **alpha は声を動かす。向きは「上げるほど参照から離れる」**——10/12 のキューで単調
  （床・2 人物・2 感情 × seed 3）。床（beta 0.0）で端まで振ると、真白の参照まで
  1.61（alpha 0.0）/ 1.77（0.35）/ 2.18（0.70）/ **2.64**（1.0）dB。ニジは
  2.33 / 2.41 / 2.55。**既定の 0.35 は、すでに 65% が参照**。
- **それでも 0 で「参照の声そのもの」にはならない。** alpha 0.0 の 1.61 dB は、
  真白とニジの参照どうしの差（1.22 dB）と同じ大きさ。**この計器の上では、参照を
  全部混ぜても、参照の録音と同じ包絡にはならない。**
- **pitch は声域を戻す**（neutral 257 → 277 Hz）。包絡は 1.69 → 1.13 dB で、こちらは
  ほとんど動かない（0.56 dB）。**戻せるのは音程で、声そのものではない。**
- beta 0.7 では pitch の指示が f0 を動かさなかった（下の「直しても動かなかったもの」）。
  **ノブが効くのは、beta を下げた側だけ。**

### 感情の外の軸（beta 0.3・neutral・seed 1〜3）

| 軸 | 動いたか | 実測 |
| --- | --- | --- |
| 速さ | 動く | very_slow 3.72 s / natural 2.40 / very_fast 1.97（3/3）。速さは 5.7 → 6.0 → 7.8 モーラ/秒 |
| 演技の型（delivery） | 動く | desperate 302 / aggressive 284 / intimate 276 Hz（3/3）。cold は 257 Hz で動かず |
| 声量 | 動かない | 張り（energy 中央値）−11.9 dB（normal）/ −12.2（loud）/ −11.5（whisper）。ピークは全部 0.95。**量は Mixing の利得で付ける**（三層分業の実測） |
| 息（breathiness） | 弱い | 散文に載っていなかった（heavy と none が**バイト一致**）→ 配線後、平坦度 0.0169 → 0.0191（+13%、seed 2/3） |

- delivery は 12 種のうち 4 種だけ測った。**cold は何も動かさない**——語が音の側へ届いていない。
- 囁き（volume=whisper）も平坦度 0.0168・調波比 0.519 で、基準（0.0169・0.524）と
  区別できない。**息と囁きは、まだ音になっていない。**

### 床（beta 0.0）では、軸によって伸び縮みする（27 本）

同じ条件（neutral・seed 1〜3）を床でも振った（`acting-floor-axes/`）。値は f0 中央値。

| 軸 | beta 0.3 | beta 0.0 | 差 |
| --- | --- | --- | --- |
| 基準（neutral） | 257.2 | 240.0 | −17.2 |
| 速さ very_slow / very_fast | 3.72 / 1.97 秒（間 0.058 / 0.217） | 3.87 / 1.85 秒（間 0.044 / 0.198） | **同じ** |
| delivery cold / intimate / aggressive / desperate | 257 / 276 / 284 / 302 | 246 / 246 / 249 / 271 | **幅が 45 → 25 Hz に縮む** |
| 声量 whisper / loud | 260.2 / 260.2 | 252.8 / 252.8 | **同じ**（量は動かない） |

- **感情は伸びる**（怒り − 無表情は +63 → +88 Hz）。**速さも声量も振る舞いが変わらない。**
- **delivery だけが縮む**（desperate の +45 → +31、aggressive の +27 → +9）。床では
  演技の型の語が、プロンプトの文面に薄く乗るだけになる。
- だから **「下げれば演技が全部良くなる」ではない。** 下げて伸びるのは覚醒の差、
  変わらないのは時間の軸、縮むのは型の軸。

### 感情と演技の型は、足し合わさる（beta 0.3・27 本）

感情（neutral / anger / joy）と delivery（cold / cheerful / aggressive）を
掛け合わせて測った（seed 1〜3）。f0 中央値（Hz）：

| 感情 | cold | cheerful | aggressive | 対照（controlled） |
| --- | --- | --- | --- | --- |
| neutral | 257.2 | 293.8 | 283.8 | 257.2 |
| anger | 293.8 | 345.3 | 353.4 | 320.4 |
| joy | 309.4 | 341.4 | 351.4 | 326.0 |

- **どちらの振り幅も 40〜60 Hz で、大きさは同じくらい。** delivery を変えると
  neutral は +27（cheerful）、anger は +60（aggressive）。感情を変えると同じ delivery で
  +52（cold）〜+69（aggressive）。
- 重なりは大きいが、足し算ではない。neutral+cheerful（294）と anger+cold（294）は
  同じ高さに着く一方、neutral からの anger の上がり幅は cold で +37・aggressive で +69。
  **「感情」と「型」は別々の軸ではなく、同じ覚醒のダイヤルを別方向から回している。**
- cold は neutral を低い側に留める（257）が、anger を消さない（294）。**型は感情を
  mask しない。**

### 作品の単位でも、声は離れず、語りが長く続く（演劇の beta 0.3 版）

同じ脚本・同じ seed・同じ間で、演劇だけ beta を 0.3 に組み直した
（[examples/longform-drama-beta03/](../../examples/longform-drama-beta03/)）。

| 項目 | 0.7 | 0.3 |
| --- | --- | --- |
| 尺 | 310.5 s | 332.2 s（+21.7 s・+7.0%） |
| 声の実時間（切った後） | 217.3 s | 239.0 s |
| 生の声の合計（切る前） | 271.3 s | 271.1 s |
| 参照との包絡の距離（89 本の中央値） | 2.11 dB | 1.99 dB |

生の声は同じ長さなのに、頭尾を切った後の声は 21.7 秒長い。**beta 0.3 の声は無音の
割合が低く、語りが長く続く。** 尺の差はこれで、間を足したのではない。
cue ごとの f0 の差は小さく（s09 267.8 → 255.7 Hz など）、この脚本はもともと
delivery・速さで演技を置いているため、beta を下げても二重に動くだけになる。

床（0.0）でも同じ脚本を組み直した（[examples/longform-drama-beta00/](../../examples/longform-drama-beta00/)）。
89 キューの包絡の距離は **2.11 → 1.99 → 2.23 dB**（0.7 / 0.3 / 0.0）で、三つとも
同じ幅の中（参照どうしの最小差 1.22 dB と同程度）。尺は 310.5 → 332.2 → **339.1 秒**、
生の声は三つとも 271 秒台で同じ。**段を下ろすほど語りが残るが、声は遠くならない。**
動くのは状態のほう（間 0.220 → 0.190 → 0.127・抑揚 8.40 → 7.90 → 7.30 半音・
有声率 0.311 → 0.405 → 0.459）。

### 作品の段で、床は何を広げ、何を平らにするか（89 キュー×3 版）

同じ脚本・同じ seed・同じ間の三つの版を、キューごとに `bin/act_probe.py` の指標で測った
（`projects/longform/drama-level/levels.tsv`・267 行）。f0 は有声区間の中央値。

| 指標 | 0.7 | 0.3 | 0.0 |
| --- | --- | --- | --- |
| 感情 8 種の平均 f0 の幅 | 48.2 Hz | 47.4 Hz | **79.1 Hz** |
| 台詞ごとの f0 の動き（0.7 との差の中央値） | — | 12.9 Hz | **20.3 Hz** |
| 感情の偏りを除いた二人の高さの差 | −8.5 Hz | −2.0 Hz | **+0.1 Hz** |
| 感情平均を引いた残差の SD（台詞ごとのばらつき） | 30.1 Hz | 21.0 Hz | 21.9 Hz |
| 抑揚の幅（8 感情の平均・半音） | 8.72 | 8.01 | **7.40** |
| 参照との包絡の距離（dB・89 本の中央値） | 2.11 | 1.99 | 2.23 |

- **広がるのは「感情の段差」。** 感情ごとの平均 f0 は fear 337.7 → 351.8、calm 299.6 →
  272.7。感情の幅は 48.2 → 79.1 Hz に開く。台詞ごとの動きも 0.7 からの中央値で 20.3 Hz。
- **平らになるのは「人物の高さ」。** 参照は真白 297.2 / ニジ 322.2 で 25.0 Hz 離れている。
  作品の中でも 0.7 では感情の偏りを除いて −8.5 Hz の差があるのに、0.3 で −2.0、
  0.0 で **+0.1 Hz**。床では prosody が全部プロンプトの散文由来になり、散文は誰が
  喋るかを知らない。**高さで二人を分けるなら、床は使えない。**
- **もう一つ平らになるのは「声の起伏」。** 感情ごとの抑揚の幅は 8 種のうち 7 種で
  0.0 がいちばん狭い（sadness 8.06 → 6.00、loneliness 7.86 → 5.14 半音）。
  **高さの段差は開くのに、声の中の起伏は縮む**——床は「平らに喋る」のではなく
  「決めた高さから動かない」。
- **台詞ごとのばらつきは減る**（感情平均を引いた残差の SD 30.1 → 21.9 Hz）。
  0.7 では台詞ごとに演技がばらつき、床では感情の名前どおりにそろう。
- **音色は、高さと別に動かない。** 二人の中心どうしの距離は 11.9 → 11.4 → 11.7 で
  ほぼ動かず、本人の中の広がり（25〜32）より小さい。三つの版はどれも、本人の参照の
  ほうが相手の参照よりわずかに近い（真白 36.8 対 39.7 / 37.4 対 40.3 / 34.8 対 37.9）が、
  ニジは 0.7 でほぼ同点（41.6 対 40.8）なので、**この計器でニジの同一性は言えない**
  （床のせいではない）。**声質では二人は分かれない**——分けるのは帯域の設計（後述）。

**床は「一人の演技の上限」を見る段で、二人芝居の上限ではない。** 作品で使うなら 0.3 まで
（尺 +7.0%）。

### seed を替えても、構造は動かない（3 本）

上の数は seed 1 の 1 本から出ている。同じ床の演劇を **cue の `seed` だけ** 2・3 に
変えて作り、作品の段の数が seed に依るかを測った（`seed-robustness/`・267 行）。

| seed | 感情 8 種の平均 f0 の幅 | 二人の差 | 抑揚 | 間 | 声の合計 | 完成の尺 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 79.1 Hz | +0.06 Hz | 7.40 | 0.136 | 271.6 秒 | 339.1 秒 |
| 2 | 66.2 Hz | +0.66 Hz | 7.46 | 0.136 | 271.6 秒 | 339.0 秒 |
| 3 | 70.6 Hz | +1.07 Hz | 7.45 | 0.137 | 271.6 秒 | 339.1 秒 |

- **構造は seed に依らない。** 声の合計は 3 本とも 271.6 秒（0.1 秒以内）、間 0.136〜0.137、
  抑揚 7.40〜7.46。キューごとの f0 の相関は seed 1↔2 で 0.979・1↔3 で 0.989。
  8 感情を平均 f0 の高い順に並べると **3 本とも同じ順**。
- **二人の差は、どの seed でも ~0**（+0.06 / +0.66 / +1.07 Hz）。「床は二人の高さを
  同じにする」は seed に依らない。
- **動くのは「感情の幅」だけ**（79.1 / 66.2 / 70.6 Hz）。差を作るのは fear
  （351.8 / 338.9 / 343.4 Hz）と anger。**79.1 は 1 つの seed の値で、3 seed では 66〜79 Hz。**
  この報告の作品の段の数は、この幅だけを「seed で動く数」として読む。

### 話が進むほど、二人の高さは同じ向きに寄る（3＋2 本）

「二人の差は +0.1 Hz」は作品全体の平均。**前半・中盤・後半に割ると、平均が隠している
動きが出る**（`seed-robustness/measure_drift.py`）。感情の平均を引いた残差で、
真白 − ニジ を区間ごとに取った。

| 版 | 前半 | 中盤 | 後半 |
| --- | --- | --- | --- |
| 床 0.0・seed 1 | −11.3 | +1.4 | +12.2 |
| 床 0.0・seed 2 | −8.3 | +1.0 | +11.4 |
| 床 0.0・seed 3 | −9.5 | +2.1 | +12.8 |
| 既定 0.7・seed 1 | −20.3 | −9.7 | +7.1 |
| 既定 0.7・seed 2 | −14.1 | −9.4 | −1.0 |

- **向きは 5 本とも同じ。** 真白が上がり、ニジが下がる。床では +20〜21 Hz、
  既定 0.7 でも +13〜27 Hz 動く。**参照の差（25 Hz）に匹敵する大きさ。**
- **これは「モデルが長尺で疲れる」話ではない。** キューは 1 本ずつ独立に生成され、
  設定と seed が同じなら同じ音になる。**位置そのものは音を変えられない**ので、
  この drift は**台本の設定の composition** からしか出ない（後半の真白は
  `desperate` 0→4・`whisper` 0→3・`very_slow` 0→4）。
- **だから、参照が 25 Hz 離れていても、作品の中では前半の差が後半に消える。**
  既定 0.7 版の前半は −20.3 Hz（ニジが上）でも、後半は +7.1 Hz（真白が上）になる。
  seed 2 では後半 −1.0 Hz で、**入れ替わりまでは言えない**（消えるところまで）。
- 加算モデル（感情・強度・音量・速さ・演技の型の効果を足す）ではこの drift を
  再現できなかった。**効き方が感情に食われる**のと同じく、要因は足し合わさらない。

### 床で二人を分けるには、pitch を人物に振る（24＋36＋48 本）

床で参照の高さが消えるなら、高さを Direction 側に書けば戻るか。まず同じ台詞
（「明日、また来るね。」・neutral・`delivery` controlled）を、pitch 4 段 × 参照 2 つ
（真白・ニジ）× seed 1〜3 で作った（`acting-floor-pitch/`・beta 0.0・alpha 0.35）。
括弧内は seed 3 本の SD。

| pitch | 真白 | ニジ |
| --- | --- | --- |
| very_low | 225.0 Hz（1.7） | 224.3 Hz（1.6） |
| low | 243.3 Hz（0.7） | 240.9 Hz（1.7） |
| natural | 241.5 Hz（6.4） | 243.0 Hz（0.9） |
| high | 272.6 Hz（4.7） | 273.1 Hz（3.2） |

- **参照を替えても、同じ高さになる**（同じ段で最大 2.4 Hz 差）。床では高さが prosody
  （＝散文）だけで決まる。
- **very_low → high で 47.6 / 48.8 Hz。** 参照どうしの差（25.0 Hz）より広い。
- **4 段は 3 段**（low と natural は同じ音。`low` は 243.3 / 240.9、`natural` は
  241.5 / 243.0 で、二人の間で順が入れ替わる）。実質 very_low・natural・high の 3 つ。
- **この段の MFCC 距離は読まない**（pitch をまたぐと倍音の間隔が動く）。包絡で測ると
  very_low 3.08 / low 2.82 / natural 1.69 / high 1.10 dB で、**低くするほど包絡も
  参照から離れる**（3.08 − 1.10 = 1.98 dB は、参照どうしの最小差 1.22 dB より大きい）。
  pitch の語は高さだけでなく、声の明るさも動かす。

だが、この 48 Hz は「neutral の 1 行」の話で、そのまま台詞の並びには持ち込めない。
4 感情 × pitch 3 段 × seed 3（`acting-pitch-emotion/`・36 本）で測ると、
**効き方は感情に食われる**。

| 感情 | very_low | natural | high | high − very_low |
| --- | --- | --- | --- | --- |
| neutral | 224.3 | 260.1 | 292.7 | **+68.4 Hz** |
| joy | 280.6 | 330.1 | 326.9 | +46.3 Hz |
| sadness | 274.7 | 281.0 | 284.1 | +9.4 Hz |
| anxiety | 295.2 | 303.5 | 308.9 | +13.7 Hz |

**もう高い台詞には、足す余地がない**（sadness・anxiety は 10〜14 Hz）。

では場面ではどうなるか。8 行のやりとりを、ニジ `high`・真白 `very_low` と、二人とも
`natural` の二通りで、seed 1〜3 ずつ作った（`floor-pitch-pairs/`・48 本）。
ニジ − 真白 の f0 の差：

| 行の組 | pitch を振る | 対照 |
| --- | --- | --- |
| もしもし。/ ……まだ起きてたの。 | +23.2 Hz | −3.8 Hz |
| うん。眠れなくて。/ そう。 | +48.0 Hz | −16.5 Hz |
| そっちは。/ こっちも、同じ。 | +51.5 Hz | +67.2 Hz |
| じゃあ、ちょっとだけ。/ ちょっとだけ。 | +35.0 Hz | +4.6 Hz |
| 12 組でニジが上 | **12/12** | 6/12 |
| 中央値 | **+41.5 Hz** | +0.5 Hz |

- **上下は作れる。** 振った版は 12 組すべてでニジが上。対照は 6/12 で、並びは感情に
  引っ張られる。聴き比べは [examples/longform-floor-two-speakers/](../../examples/longform-floor-two-speakers/)。
- **狙った高さには置けない。** 1 行ずつの効きは −36 〜 +28 Hz に散る
  （high は −20〜+28、very_low は −4〜−36）。感情の高い行では動かない。
- **pitch の語は時間も動かす**。1 行の実験では very_low 3.25 秒 / natural 2.25 秒。
  場面では逆に pitch 版が短い（声の合計 49.3 対 63.0 秒）。向きは一定でない。

### 作品の 89 本で振ったら、上下は開いたが尺が割れた（`drama-beta00-pitch/`）

12/12 が作品の段でも成り立つか。床の演劇の全 89 キューに、真白 `very_low`（47 本）・
ニジ `high`（42 本）を書き、ほかは何も変えずに組み直した。

| 項目 | 床（beta 0.0） | 床＋pitch |
| --- | --- | --- |
| 尺 | 339.1 秒（門 合格） | **291.0 秒（門 未達）** |
| 生の声（切る前） | 真白 134.1 / ニジ 137.5 秒 | **真白 89.0** / ニジ 139.2 秒 |
| f0 の中央値 | 真白 311.2 / ニジ 316.7 Hz | 真白 295.5 / ニジ 318.5 Hz |
| 感情の偏りを除いた差（真白 − ニジ） | +0.06 Hz | **−13.38 Hz** |
| 感情 8 種の平均 f0 の幅 | 79.1 Hz | 69.5 Hz |
| 抑揚（8 感情平均・半音） | 7.40 | **6.20**（真白 7.08 → 4.93 / ニジ 7.66 → 7.45） |
| 隣の真白よりニジが上 | 21/42 | **31/42** |

- **上下は開く。** 感情の偏りを除いた差は +0.1 → −13.4 Hz で、既定 `beta` 0.7 版の
  −8.5 Hz より広い。隣と比べても 21/42 → 31/42。**ただし 12/12 ではない**——
  作品では 1 行ずつ感情が違い、高い台詞では余地がない（前節）。
- **`very_low` は高さだけを動かさない。** 真白の声は同じ台詞・同じ seed で
  134.1 → 89.0 秒（−33.6%）。間が落ち、抑揚が 7.08 → 4.93 半音に潰れる。
  ニジの `high` は 137.5 → 139.2 秒でほぼ動かない（長さの比の中央値：真白 0.639 /
  ニジ 1.01）。**語の効きは左右で非対称**で、下げる側だけが演技を組み直す。
  短縮は**長いテイクに集中する**——1 キューあたりの中央値で、囁き −2.30 秒・
  quiet −1.34・normal −0.46、very_slow −1.69・slow −1.35・natural −0.28。
  **尺を使っている台詞ほど削られる。**
- **その代償が尺に出る。** 48.1 秒縮んで 291.0 秒。5 分の門に 9 秒届かない。
  門の他（ピーク −0.4・クリップ 0・効果音 +40.1 / +22.2 dB・ducking −11.6 dB）は通る。
- **pitch は DSP のノブではない。** プロバイダに渡す散文の一文
  （`with a very low pitch`）で、モデルはその一文ごと演技を組み直す。
  高さを狙って置く道具としては、まだ粗い。

### 同じ seed でも、最後のビットまでは同じにならない

同じ設定（alpha 0.35・beta 0.3・同じ seed・同じ台詞）で別プロセスから作り直した 12 本のうち
**5 本がバイト不一致**。差は RMS 0.0005〜0.0007（信号に対して約 −65 dB）で、長さは同じ。
聞こえは変わらず、この報告の結論も動かない。ただし「同じ seed で byte-identical」と
書くのは言い過ぎで、正しくは「同じ長さ・差は −65 dB 程度」。

**1 本に絞って 6 回**確かめた（`determinism/`・beta 0.7・同じ Spec・同じ seed 3）。

- **6 本が 2 種に割れた**（`954f9db` ×3 → `2d575e2` ×3）。差は最大 0.0119・
  RMS **−64 dBFS**・相関 0.999994。**長さ 65,950 サンプルとピーク 0.94995 は同じ。**
- **`act_probe.py` の 14 欄は全部同じ**（f0 314.9 Hz・抑揚 8.4 半音・間 0.184 …）。
  **測った結論は、この差に影響されない。**
- **同じプロセスの中なら一致する**（3 回続けて差 3e-6 = 1 LSB）。アラインメントをずらしても
  3e-6。**1 スレッドでも 2 種に割れる。** → プロセスをまたぐ何かが最後の桁を変える
  （**特定していない**）。
- 差は発話の真ん中に寄り、頭と尻尾（無音）では 0。**聞いて区別できない。**
- 困るのは **md5 で「同じ音か」を検査するとき**。一致を見たいなら同じプロセスで 2 回焼く。

### 枠外 10 種 × seed 5（P2 の再測）

1 seed だけで「完全 4 / 部分 2 / 動かず 4」と読んだが、それは seed の揺れを演技の差と
取り違えていた。**同じ 10 種を seed 1〜5 で振り直した**（55 本・同じ台詞・同じ人物・
`--resolve rule`）。判定は「狙った向きへ動いた seed が 5/5 か」。

| 種 | 狙い | 正しい向きの seed |
| --- | --- | --- |
| 早口 hayakuchi | 短い | **5/5**（2.30 s / 基準 2.97 s） |
| 間 ma | 長い | **5/5**（4.12 s / 基準 2.97 s） |
| 皮肉 hiniku | 語尾↓・遅い | 2/5・1/5 |
| 諦め akirame | 張り↓・遅い | 2/5・1/5 |
| 独白 dokuhaku | 張り↓・遅い | 3/5・1/5 |
| 照れ tere | 張り↓ | 3/5 |
| 虚勢 kyosei | 張り↑ | 3/5 |
| 囁き sasayaki | 張り↓ | 3/5 |
| 怒鳴り donari | 張り↑ | 2/5 |
| 泣き笑い nakijwarai | 抑揚↑ | 3/5 |

**確実に動くのは「時間」だけ。** ほかは seed の揺れと区別できない。
遅いと指定した 5 種（皮肉 3.42・諦め 3.45・独白 3.50・囁き 3.35・間 4.12 秒）も、
長さだけは 5/5 で伸びた。

- 基準線そのものの f0 は 241〜326 Hz（5.2 半音）も揺れる。怒鳴りの f0 279〜364 Hz は
  **その範囲に完全に収まる**。
- 時間以外に 5/5 で分かれたのは、速さに随伴する**立ち上がり**（諦め 190 ms・早口 80 ms・
  間 270 ms／基準 140 ms）。
- 囁きは帯域でも分かれなかった（高域 −13.5 dB・平坦度 0.0307／基準 −14.1 dB・0.0285。
  種の中の幅 −15.5〜−13.4 dB のほうが大きい）。
- 「間」は間（pause_ratio）ではなく**遅さと出だしの遅れ**で出た（間 0.26／基準 0.27）。
- ⚠️ `energy_median` は無音フレームも数えるので、長い台詞ほど低く出る。
  「間」の −15.7 dB は長さの分が混ざっている（計器の限界）。

### 機構の穴（直した）

1. `intensity` が散文に載っていなかった（anger subtle と strong が**バイト一致**）。
   `_INTENSITY_PHRASES` を足した。
2. `pitch` を `capabilities()` が名乗っているのに散文へ渡していなかった。
   `PITCH_PHRASES` を足した。
3. `volume`（whisper〜shout）が `effort` に潰れて囁きが消えていた。`loudness.volume` を
   schema・resolve・provider に通した。
4. `breathiness` は schema・CLI・scene が受けるのに、Spec にも散文にも載っていなかった
   （heavy と none が**バイト一致**）。`prosody.breathiness` を schema・rule 解決・provider に
   通した。通した後は平坦度が動く（弱い）。

### 直しても動かなかったもの

- **声量の指示は生成音のレベルに出ない**：n05（normal）RMS −17.7 dB、n06（quiet）−17.8 dB、
  m02（loud）−16.4 dB、m03（quiet）−15.3 dB。全部 peak 0.95。**差はミックスの gain_db で作る**
  （三層分業の実測）。
- **pitch の指示は f0 を動かさない**：very_low 347.3 / slightly_low 347.3 / low 353.4 Hz
  （0.3 半音。seed の揺れより小さい）。⚠️ これは beta 0.7 の測定。beta 0.3 では
  257 → 277 Hz と動く（上の「声そのものは alpha でも pitch でも戻らない」）。

## 声は分けられるか（P4）

同じ台詞を二人の人物で作り、有声フレームの距離を測った。3 台詞 × 2 人物 × seed 3
＝18 本（`timbre-two-characters/`・beta 0.7・alpha 0.35・neutral）。

| 比較 | 組 | 距離（中央値） | 範囲 |
| --- | --- | --- | --- |
| 同一人物（同じ台詞・seed 違い） | 18 | 16.4 | 9.9–30.4 |
| 別人（同じ台詞・同じ seed） | 9 | 13.8 | 9.6–31.6 |

**别人の差が、同一人物の seed の差より小さい。** 声そのものでは二人を聞き分けられない
（旧い計器では 24.6 対 9.9 と出ていたが、向きは同じ）。そこでニジだけ電話の帯域
（320〜3400 Hz）に通した（`drama/voice_fx.yaml`）。真白の参照までの距離は
47.1 → **140.9**、包絡で 1.95 → **9.60 dB**（参照どうしの最大差 5.52 dB より大きい）。
低域 −12.2 → −20.9 dB、重心 694 → 583 Hz。帯域は演技ではなく配色の層で、
**声質で二人を分ける唯一の実測された手段**。

### 分かれるかどうかは、参照の組で決まる（解説の 48 本）

演劇の二人は分かれなかったが、解説「音は、なぜ感情を動かすのか」の**語り手と真白は
分かれる**（`explainer-level/`・語り手 44 本・真白 4 本）。同じ計器で測ると：

| 比べるもの | 包絡の距離 |
| --- | --- |
| 語り手の中心 ↔ 真白の中心 | **4.68 dB** |
| 語り手の中の広がり（946 組の中央値） | 1.40 dB |
| 真白 4 本の広がり（6 組の中央値） | **0.50 dB** |
| 参照どうし（語り手 ↔ 真白） | 4.68 dB |
| 参照どうし（真白 ↔ ニジ） | **1.22 dB**（ライブラリで最も近い） |

- **分かれるのは、参照の組が離れているから。** 語り手↔真白は 4.68 dB、真白↔ニジは
  1.22 dB。生成の仕組みは同じなので、**二人を分けられるかは、どの参照を選ぶかで決まる**。
- **高さでも分かれる。** 語り手 261.4 Hz（237.9–295.5）・真白 351.4 Hz（326.0–355.5）。
  44 本の最大と 4 本の最小が重ならない。
- **演技は、声質をほとんど動かさない。** 同じ台詞を 4 通りに演じても包絡は 0.50 dB
  （0.11–0.64）。一方で高さは 29.5 Hz 動く。**演技で動くのは状態で、器ではない。**
  seed を替えると包絡は 0.85〜1.06 dB 動くので、演技の 0.50 はその内側に入る。
- **同じ人物でも、作品が違えば高さは動く。** 解説の真白 351.4 Hz と演劇の真白 304.1 Hz
  （0.7 版・47 本）。**47 Hz。** 台詞の感情の混ざり方が違うため（本数は 4 と 47）。

### 高さは seed が決め、声質は seed も方向も動かす（`explainer-joy/`）

解説の「三通り」の 2 つめ（励まし）と 3 つめ（照れ隠し）が**ほぼ同じ音**だった。
同じ 1 行・同じ人物で、方向を振った本と seed を振った本を並べて測った。

距離はすべて、本番の励まし（m02・seed 1）から測った。

| 並べた本 | f0 中央値 | 包絡（m02 から） | MFCC（m02 から） |
| --- | --- | --- | --- |
| seed 1・**方向違い 4 本**（m04・alt 3 本） | 335.5〜355.5 Hz（幅 **20.0**） | 0.11〜0.58 dB | **5.4〜19.9** |
| seed 2・方向 2 通り | 304.1・305.9 Hz | 0.95〜1.06 dB | 21.6〜23.1 |
| seed 3・方向 2 通り | 315.8・318.5 Hz | 0.85〜1.02 dB | 15.2〜19.1 |

- **高さは seed が決める。** seed をまたぐと **51.4 Hz** 動く。同じ seed の中で方向を
  振っても **20.0 Hz** しか動かず、着地先は方向をまたいで 1.8〜2.7 Hz しか違わない。
- **声質は違う。** seed の揺れ（MFCC 15.2〜23.1）と方向の振れ（5.4〜22.3）は**重なる**。
  方向が効かないのではない。
- **本番の 2 本の差は、方向を振った中でいちばん小さい側**（MFCC 5.4）。同じ台詞でも
  `neutral/gentle` を選べば m02 から 19.9・m04 から 22.3 動いた。**3 つめが似て聞こえる
  のは、動く幅の小さい選び方だったから**であり、モデルが方向を無視しているからではない。
- ⚠️ 1 行・1 人・3 seed の話。seed をまたいだ一般化はしない。本番は全キュー seed 1
  なので、上の「演技で 29.5 Hz」は seed を固定した比較として読める。
- f0 は act_probe と librosa pyin の 2 本で確かめた（絶対値は違う・順序と幅は同じ）。

### 感情と seed、どちらが声を動かすか（`emotion-seed/`）

同じ台詞を 5 感情 × seed 3 つで作り（2 行 × 15 = 30 本、強度・速さ・型は固定）、
seed をブロックにして感情の効きを測った。

| 指標（1 行目） | F 感情 | F seed | η² 感情 | η² seed |
| --- | --- | --- | --- | --- |
| f0 中央値 | 56.03 | 594.82 | 0.16 | **0.84** |
| 抑揚 | 2.12 | 126.41 | 0.03 | 0.94 |
| 間 | 11.41 | 63.09 | 0.25 | 0.70 |
| 有声率 | 24.95 | 9.34 | 0.79 | 0.15 |

- **seed を誤差にすると感情は見えなくなる**（一元配置の F 0.47）。seed はばらばらに
  振れるのではなく**seed ごとに決まった高さへ寄る**（5 感情すべてで s1 が高い）ので、
  ブロックとして除くのが正しい。
- 除くと感情は効く（f0 の F 56.03・自由度 4,8 の境目 3.84）。**だが分散で見ると
  seed が 84%・感情が 16%。** 2 行目は 93% / 6%。**高さの主役は seed。**
- **並びは seed をまたいで同じ**（neutral < sadness < fear/anger < joy、順位相関
  0.70〜0.90）。seed を 1 つに固定したときの感情の幅は 19.4〜34.3 Hz で、
  **作品の中の比較（29.5 Hz）はこの範囲で成り立つ**。
- 音色も seed のほうが動く（同じ感情で seed を替えると MFCC 16.86・14.89、同じ seed
  で感情を替えると 7.08〜10.69）。
- **seed の振れ幅は行で変わる**（1 行目 49.0 Hz・2 行目 83.5 Hz）。揺れの量を作品の
  ノイズとして持ち出すときは、その行で測る。

### seed の癖は声をまたぐ（`seed-voices/`）

同じ 1 行を 4 つの声（narrator / mashiro / niji / katari）× seed 1〜3 で作った（12 本）。

| 声 | s1−平均 | s2−平均 | s3−平均 | 幅 |
| --- | --- | --- | --- | --- |
| narrator 253.4 Hz | +17.6 | −3.5 | −14.1 | 31.7 Hz |
| mashiro 299.0 Hz | +27.0 | −18.5 | −8.6 | 45.5 Hz |
| niji 314.1 Hz | +21.4 | −18.6 | −2.9 | 40.0 Hz |
| katari 291.6 Hz | +26.9 | −19.1 | −7.8 | 46.0 Hz |

- **符号は 4 声とも「＋ − −」**（相関 0.74〜1.00）。**seed は声に依らない癖**で、
  真白 1 人で見えたことは 4 声へ広がる。大きさは声で違う（32〜46 Hz）。
- **音色では、seed を替える動きが「人物を替える」動きと同じ大きさ。** 同じ声で seed を
  替えると MFCC 12.8〜17.1、mashiro↔niji↔katari の距離は 13.0〜13.5、narrator は
  63.4〜68.7。**seed を固定しないと、人物の差と seed の差が同じ土俵に乗る。**

### 同じ seed どうしで読み直すと、演技は基準線より必ず上がる（`acting/reanalyze_seeds.py`）

P2 の 55 本（枠外 10 種 × seed 1〜5・同じ台詞）を、seed をブロックにして読み直した。
P2 の判定は「種の 5 seed が**基準線の中央値**より狙った向きに出た数」だったが、
**seed をそろえれば同じ seed どうしを直接比べられる**。

| 指標 | F 種（df 10,40） | p | η² 種 | η² seed |
| --- | --- | --- | --- | --- |
| 長さ | 315.41 | 9.1e-35 | 0.73 | 0.26 |
| f0 | 63.87 | 2.2e-21 | 0.13 | 0.86 |
| 立ち上がり | 31.11 | 9.1e-16 | 0.61 | 0.31 |
| 間 | 7.04 | 3e-06 | 0.12 | 0.81 |
| 有声率 | 6.00 | 1.7e-05 | 0.38 | 0.37 |
| energy | 4.03 | 0.00072 | 0.20 | 0.61 |
| 抑揚 | 3.44 | 0.0025 | 0.07 | 0.85 |
| 速さ | 1.70 | 0.11 | 0.26 | 0.12 |

- **f0 は 10 種のうち 8 種が、5 seed すべてで基準線より高い**（akirame +5.0・dokuhaku
  +9.7・donari +39.2・hayakuchi +32.2・kyosei +17.5・ma +16.2・nakijwarai +30.4・tere
  +26.6 Hz。hiniku +3.7・sasayaki +4.3 は 4/5）。**下がる種は無い。**
- **上がり幅は感情の欄に沿う**：joy +26.6/+30.4・anger +39.2・anxiety +32.2・
  confidence +17.5／sadness +16.2・+4.9・loneliness +9.7・neutral +4.3・calm +3.7。
  `emotion-seed/` の順序（joy/anger > sadness > neutral）と重なる。**ただし種は
  1 感情 1 つなので、これは仮説であって検定ではない。**
- **狙った向きには依然として動かない。** 皮肉の「語尾↓」・囁き/諦めの「張り↓」は
  5/5 にならず、energy で基準線と有意に違ったのは ma だけ（しかも長さの交絡）。
  **P2 の「意味の写像ではない」はそのまま。** 動くのは「演じている声の高さ」で、
  「皮肉らしさ」ではない。
- 速さ（mora/s）だけは種で分かれない（F 1.70）。**長さが動くのは速さではなく間**
  （間の F 7.04・立ち上がり F 31.11）。

### 全キュー総当たりで「同じ声になった組」を探す（`near_duplicates.py`）

方向を変えたのに声が似る、ということが他の作品にもあるかを、有声フレームの MFCC で
全組について測った。物差しは**その作品の中の分布**。

| 作品 | 本 | 組 | 中央値 | 下位 5% | いちばん近い組 |
| --- | --- | --- | --- | --- | --- |
| 演劇 0.7 | 89 | 3,916 | 40.25 | 19.89 | **s01↔s68 = 0.00**（同じ台詞・同じ設定） |
| 解説 | 48 | 1,128 | 23.09 | 9.90 | n05↔n10 = 3.81（同じ設定の語り手） |

- **0.00 は欠陥ではなく確認。** s01 と s68 はどちらも「……もしもし。」・同じ設定・seed 1。
  決定的生成なので同じ音が出る（開幕と終盤に同じ一行を置いた設計）。
- **解説の m02↔m04 = 5.57 は、この作品で 2 番目に近い組。** 1 位は設定の同じ語り手。
  **方向を変えた組としては最も近い**——`explainer-joy/` の結論を、作品の中の分布で裏づける。
- 演劇で 2 番目に近い s25↔y07（6.90）は「……それだけ。」と「それだけ。」で、
  台詞がほぼ同じ。**近さの多くは、台詞が同じことで説明できる。**

## 組み立てで踏んだ穴

- キューを切らずに並べると、置いた間が **1 秒ずつ伸びる**（各 WAV の頭尾に無音）。
  切ったら 312.4 s → 287.1 s。尺は切ったあとで数える。
- 切った WAV を 16 bit で書くとき `astype(int16)` だけでは **全部 0 になる**（−1〜1 のまま）。×32767。
- 3 秒の鐘を章の頭（間 1〜3 秒）にそのまま置くと台詞に重なる。1.4 秒に切って 1.6 秒手前へ。
- 語り手のキューの生成は**1 プロセスで 33 本、1 本 1.0〜1.6 秒**（モデルのロードは 1 回）。
  CLI を 1 本ずつ起こすと毎回 ~1 分のロードが付く。

### 音量（配布の目安との距離・`check_loudness.py`）

ピークの正規化（0.95）は「いちばん大きい瞬間」をそろえるだけで、**体感の音量は
そろわない**。ffmpeg の loudnorm で測った（目安は配布先の慣習で、この工房の裁定ではない）。

| 仕上げ | 統合 | トゥルーピーク | 幅 LRA |
| --- | --- | --- | --- |
| 解説 | **−17.44 LUFS** | −0.42 dBTP | 8.20 LU |
| 演劇 0.7 | −16.25 LUFS | −0.45 dBTP | 9.00 LU |
| 演劇 0.3 | −16.24 LUFS | −0.42 dBTP | 8.50 LU |
| 演劇 0.0 | −16.02 LUFS | −0.44 dBTP | 9.30 LU |
| 演劇 0.0＋pitch | −16.68 LUFS | −0.44 dBTP | 9.40 LU |

- **二本の間で 1.2 LU 違う**（解説 −17.44・演劇 −16.25）。ポッドキャストの目安
  −16 LUFS から見ると、演劇はほぼ当たり、解説は 1.4 LU 低い。
- **トゥルーピークは −0.42〜−0.45 dBTP。** クリップはしていない（サンプルは 0 を
  踏んでいない）が、配布の慣習（−1 dBTP 以下）より 0.6 dB 高い。MP3 にした後も
  −0.68〜−0.71 dBTP で、0 dBTP は超えない。
- **この工房では音量をそろえる段をまだ持っていない**（`assemble.py` はピークでしか
  正規化しない）。そろえるなら仕上げの後段に −16 LUFS のゲインが要る。

### 配布の高さを −1 dBTP へ（`deliver.py`）

見本の mp3 9 本を、**9 本とも同じ −0.45 dB** の直線ゲインで焼き直した。
圧縮も limiter も掛けていない。**マスター（`assets/*/renders/*.wav`）は触っていない。**

| 見本 | 統合（mp3） | トゥルーピーク | チャンネル |
| --- | --- | --- | --- |
| 解説 | −18.16 LUFS | −1.14 dBTP | stereo |
| 演劇 0.7 | −16.96 LUFS | −1.17 dBTP | stereo |
| 演劇 0.3 | −16.95 LUFS | −1.13 dBTP | stereo |
| 演劇 0.0 | −16.73 LUFS | −1.16 dBTP | stereo |
| 演劇 0.0＋pitch | −17.40 LUFS | −1.15 dBTP | stereo |
| 演技の見本 4 本 | −16.61〜−17.64 LUFS | −1.13〜−1.15 dBTP | **モノラル**（マスターがモノラル） |

- **トゥルーピークは 9 本とも −1.1 dBTP へ入った**（元は −0.68〜−0.71）。
  同じ値を掛けたので、**作品どうしの相対の高さは動かない**。
- **音量の側はそろわない。** 解説 −18.16 と演劇 −16.73 で 1.4 LU 差のまま。
  **−16 LUFS へそろえるには圧縮が要る**——解説で計算させると −1.08 dB までしか
  掛けられず（ピークで止まる）、−18.5 LUFS にしかならない。波高率を保つことと
  高さをそろえることは両立しない。圧縮は音作りの決定なので、測る段では掛けない。
- **`-ac 2` はモノラルの音を −3 dB 静かにする。** モノ→ステレオの上げは 0.707 倍ずつ
  配るので、モノラルのマスター（−0.45 dBFS）は左右へ上げた時点で −3.45 dBFS になる。

  −0.45 dBFS と、焼いた mp3 の `loudnorm` −4.17 dBTP の食い違いで見つけた。）
  見本 4 本のマスターはモノラルなので、**チャンネル数はマスターのまま書く**。

**「−16 LUFS へそろえるには圧縮が要る」を、9 本ぶんで数で言う**（mp3 を `loudnorm` で
測った値。波高率＝トゥルーピーク − 統合）。

- 波高率が小さいほど「音が詰まっている」。**作品の音作り（間・抑揚）がそのまま
  波高率に出ている**——解説（間が長い）が 17.02 でいちばん大きい。
- **いまの examples は 31 本**（全数を `check_loudness.py` で測った）。**21 本が

測り方は `check_render.py`（尺・ピーク・クリップ・無音・立ち上がり）と
`check_duck.py`（下地が実際に何 dB 沈んだか）、`check_loudness.py`（音量）、
`deliver.py`（直線のゲインで配布 mp3 を書く）。効果音の立ち上がりは
**鳴る直前 0.5 秒の床**から測る。2 秒取ると台詞の尾を拾い、間の中の音が
「台詞より静か」に見える（実際にそう誤読した）。

### 聞き分けについて（演劇）

同じモデルの二人は、声そのものでは分かれない（上の 16.4 対 13.8）。分けたのは
**ニジの電話帯域**で、低域 5.3 dB・高域 9.3 dB の差。演技の差ではなく配色の差。

## 組み立ての決定

- **声量はミックスで作る**。生成音は peak 0.95 に揃っており、`whisper −10 / quiet −5 /
  normal 0 / loud +3 / shout +6 dB` を `assemble.py` が掛ける。
- **下地は −30 dB**。声が鳴っている間だけ ducking（`mix.py`）で沈める。
- **間を聴かせる場面は下地も止める**（解説の q01→q02 の 5 秒）。
- **効果音は cue 名を錨に置く**（`sfx.yaml`）。耳で合わせない。

## 限界

- 枠外 10 種は 5 seed で振り直した。それでも 5 本では「5/5」以外は「分からない」で
  しかない（4/5 と 1/5 の区別はつくが、その中間は言えない）。
- 11 感情も 5 seed で振り直した（10 感情 × 5 seed）。感情の名前どうしの区別は
  beta 0.3 でも anger と joy が重なる。分かるのは覚醒の段まで。
- **beta は cue ごとに書ける**（`script.yaml` の `beta:`。`build_voice.py` が読む）。
  ただし値が違えば声の寄り先も変わるので、同じ人物の台詞で混ぜると声色が動く。
- `energy_median` は無音フレームを含むので、長さと交絡する。
- 声質の計器は「フレーム平均の距離」で、話者識別の埋め込みではない。**声そのものが
  変わっていない**と言えるのは、この 2 つの物差し（有声フレームの MFCC・LPC 包絡）の
  範囲で。包絡は声道の共鳴しか見ないので、息混じり・かすれ・倍音の配分は拾わない。
- 「そこに何かがいる」は測れない。測れるのは機構だけ。
- 完成音を耳で聴いていない。無音率・クリップ・帯域・立ち上がりは測れるが、
  「泣けるか」は測れない。
